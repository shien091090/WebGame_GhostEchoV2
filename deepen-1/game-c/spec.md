# 升降接力(幽靈守開關升起升降台)

## 概述
走到終點前必須先死, 死掉的自己變成不斷重演的幽靈, 下一個自己踩它、搭它、鉤它, 讓它守住開關, 三個人內摸到旗子。這款的新機制是**開關不只開門, 還能升起升降台**: 場上有兩個開關, 一個升降台開關、一個門開關。前一代的幽靈站在升降台開關上, 下一代就能搭電梯上樓; 幽靈幫忙的方式從「當墊腳石」擴大成「替你開電梯、替你開門」, 讓玩家感覺前一代是真正的隊友, 也多出不同的解法可以摸索。
驗證假設: H17 H23 H24(並沿用 H03 H05 H07 H08 H11 H12 H13 H14 H18)

## 核心循環
第 1 代站上升降台開關守著, 替第 2 代開電梯, 然後死去 → 第 2 代搭電梯上平台一, 在平台一跳一次給第 3 代鉤、再去踩住門開關 → 第 3 代看不到第 1 代, 電梯不會升, 只能搭第 2 代幽靈的便車(它像在坐一台看不見的電梯), 上平台一後鉤它的跳躍飛上平台二, 趁門開衝向旗子 → 過關看三代合力回放(電梯和門跟著回放動起來)。

## 規則
1. 單一畫面、單一關卡, 不捲動。座標以畫布左上為原點, y 向下
2. 角色左右走、跳躍; 受重力, 落地才能起跳(地面、平台、升降台、幽靈頭頂都算落地)
3. 地面為實心; 空中平台與升降台為單向平台: 從下方可穿過, 從上方落下時會站上去
4. 角色掉出畫面下緣即死亡; 碰到尖刺即死亡
5. 共三代角色, 第 1 代開局出生在出生點
6. 每代從出生到死亡的每一幀都被記錄(60 幀/秒): 位置、朝向、動作狀態、是否著地、鉤索兩端(鉤爪拉動中才有)。錄製達 60 秒時該代自動死亡
7. 某代死亡後播放 0.6 秒死亡演出, 接著下一代在出生點出生; 升降台與門回到初始狀態後再依當下開關狀態運作
8. 新一代出生的同一幀, 上一代的紀錄從第 0 幀開始以「幽靈」重播; 播完最後一幀後立刻從第 0 幀重新開始, 無限循環
9. 場上只存在「上一代」的幽靈: 操控第 2 代時只有第 1 代幽靈; 操控第 3 代時只有第 2 代幽靈, 第 1 代幽靈完全消失(不顯示、不可踩、不可鉤、不壓開關)
10. 幽靈不受尖刺、坑洞、門、升降台影響, 純粹照紀錄重播; 紀錄中正在鉤爪拉動的幀, 幽靈連同它的鉤索一起顯示
11. 幽靈只有頭頂可以站: 角色下落時(垂直速度 ≥ 0)腳底穿過幽靈頭頂、且水平有重疊, 就站在幽靈頭上。幽靈的其他部位不擋角色
12. 站在幽靈頭上時, 角色跟著幽靈移動(水平位移相加, 腳底每幀貼齊幽靈頭頂, 幽靈上升或下降都跟著); 可以從幽靈頭上起跳; 水平走出幽靈頭頂範圍即離開
13. 幽靈循環從最後一幀跳回第 0 幀時, 站在它頭上的角色不跟著瞬移, 改為進入空中狀態
14. 前一代路線: 畫面畫出當前幽靈整條紀錄的路線(每幀幽靈中心連成線), 並標出幽靈目前播到哪一點
15. 鉤爪每人限用一次: 每一代各有 1 次鉤爪; 用掉後本代不能再鉤, 下一代出生時重新給 1 次
16. 可鉤條件: 幽靈存在、角色中心與幽靈中心距離 ≤ 鉤爪範圍、本代還有鉤爪次數。條件成立時幽靈顯示「可鉤」發光
17. 按鉤爪鍵且可鉤: 扣 1 次; 角色在拉動時間內被拉到幽靈頭頂(目標追著幽靈當下位置), 拉動期間不受重力、不能操控。拉動結束瞬間, 若幽靈當下在空中(紀錄中未著地)獲得向上「強甩速度」, 若幽靈著地獲得「弱甩速度」; 水平速度歸零, 之後在空中可左右移動
18. 按鉤爪鍵但不可鉤: 不發生任何事, 不扣次數
19. 拉動中若幽靈循環跳回第 0 幀, 鉤爪中斷, 角色以當下位置進入空中狀態(次數已扣)
20. 開關有兩個: 升降台開關(在地面)、門開關(在平台一)。開關被壓住的條件: 角色或場上的幽靈處於著地狀態, 腳底與開關所在平台表面同高, 且水平與開關有重疊
21. **升降台(新)**: 升降台開關被壓住期間, 升降台以「升降速度」往上移, 到最高點停住; 放開後以同速往下移, 回到最低點停住。站在升降台上的角色跟著上下移動。升降台最低點時頂面與地面齊平, 下方地面一直存在
22. 門在門開關被壓住期間開啟; 開關放開後經過「關門延遲」才關上。門關著時是實心牆, 角色無法穿過也跳不過
23. 門要關上的那一刻若角色與門重疊, 門延後到角色離開後才關
24. 每個開關與它控制的物件要用同一種顏色標示, 讓玩家看得出哪個開關管哪個東西
25. 「整關重來」: 回到第 1 代開局, 清空所有紀錄。沒有其他任何重來方式
26. 角色碰到終點旗即過關
27. 過關後進入回放: 第 1、2 代的紀錄與過關那一代從出生到過關的紀錄, 同時從第 0 幀開始以幽靈播放並循環; 三代都顯示(含鉤索), 兩個開關、升降台、門照回放中的壓住狀態運作; 回放時不畫路線
28. 第 3 代死亡即失敗

設計意圖(給 RD 驗算用, 不給玩家看):
- 一般跳 168 px; 踩頭 +56; 搭著跳躍中的幽靈再在最高點跳, 最多 392 px。兩段平台高差都是 420 px, 只能靠升降台或鉤騰空幽靈(從它頭頂甩 300 px, 幽靈離地 ≥ 64 px 時鉤才夠)
- 第 1 代一個人無法同時壓開關又搭電梯, 必死。主解: 第 1 代守升降台開關約 4 秒以上(走到電梯約 1.6 秒 + 升降 2.1 秒), 之後走進右邊坑結束
- 另解: 第 1 代在地上 x 60~440 跳, 第 2 代鉤它上平台一(用掉第 2 代的 1 次)。兩種解法都成立, 讓玩家有得摸索
- 第 2 代上不了平台二(地上的第 1 代幽靈最高只甩到腳底 y≈676)。它要在平台一 x 240~440 跳一次給第 3 代鉤, 然後踩住門開關不放(之後可走進左邊尖刺結束)
- 若第 2 代改去守升降台開關讓第 3 代搭電梯, 平台一上就沒有幽靈可鉤、也沒人開門 → 不成立; 這是讓玩家體會「哪一代守哪個開關」的取捨
- 第 3 代看不到第 1 代, 升降台不會升; 上平台一要先跳上第 2 代幽靈的頭(在地上時頭頂離地 56 px, 一般跳得上), 被它載上去; 若在這裡用掉鉤爪, 之後上不了平台二
- 門頂 y=140; 從平台二跳最高腳底 y≈192, 鉤爪甩最高腳底 y≈256, 都過不了門

## 勝負與結束
- 勝利: 任一代角色碰到終點旗 → 顯示過關字樣並播放三代同時回放, 按空白鍵回到第 1 代開局
- 失敗: 第 3 代死亡 → 顯示失敗畫面, 按空白鍵回到第 1 代開局
- 開啟網頁先顯示說明頁, 翻完進入遊戲

## 範圍邊界
- 只有一關, 無難度曲線、無計分
- 無怪物; 無「這一代重來」、無重錄上一代, 只有整關重來
- 鉤爪只能鉤幽靈, 不能鉤平台、牆或升降台
- 只有一個升降台、一組門
- 升降台不會夾死角色(從下方穿過)
- 無音效、無存檔、無慢動作
