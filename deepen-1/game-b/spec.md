# 共鉤(鉤爪次數三代共用)

## 概述
走到終點前必須先死, 死掉的自己變成不斷重演的幽靈, 下一個自己踩它、搭它、鉤它, 讓它守住開關, 三個人內摸到旗子。這款的新機制是**鉤爪次數三代共用, 全關只有 2 次**: 每一次出鉤都是在花全隊的資源, 前一代要想清楚「我用掉這次, 下一代還夠不夠」, 下一代也要想「能搭便車就別花鉤爪」, 讓接力規劃延伸到資源分配。
驗證假設: H17 H21 H22(並沿用 H03 H05 H07 H08 H11 H12 H13 H14 H18)

## 核心循環
第 1 代在地上跳一段給第 2 代鉤, 然後死去 → 第 2 代鉤它飛上平台一(花掉 1 次), 在平台一跳一次給第 3 代鉤、再去踩住開關 → 第 3 代站上第 2 代幽靈的頭, 被它的那一鉤免費載上平台一, 用最後 1 次鉤爪鉤它的跳躍飛上平台二, 趁開關被踩住時過門 → 過關看三代合力回放。

## 規則
1. 單一畫面、單一關卡, 不捲動。座標以畫布左上為原點, y 向下
2. 角色左右走、跳躍; 受重力, 落地才能起跳(地面、平台、幽靈頭頂都算落地)
3. 地面為實心; 空中平台為單向平台: 從下方可穿過, 從上方落下時會站上去
4. 角色掉出畫面下緣即死亡; 碰到尖刺即死亡
5. 共三代角色, 第 1 代開局出生在出生點
6. 每代從出生到死亡的每一幀都被記錄(60 幀/秒): 位置、朝向、動作狀態、是否著地、鉤索兩端(鉤爪拉動中才有)。錄製達 60 秒時該代自動死亡
7. 某代死亡後播放 0.6 秒死亡演出, 接著下一代在出生點出生
8. 新一代出生的同一幀, 上一代的紀錄從第 0 幀開始以「幽靈」重播; 播完最後一幀後立刻從第 0 幀重新開始, 無限循環
9. 場上只存在「上一代」的幽靈: 操控第 2 代時只有第 1 代幽靈; 操控第 3 代時只有第 2 代幽靈, 第 1 代幽靈完全消失(不顯示、不可踩、不可鉤、不壓開關)
10. 幽靈不受尖刺、坑洞、門影響, 純粹照紀錄重播; 紀錄中正在鉤爪拉動的幀, 幽靈連同它的鉤索一起顯示(鉤索的另一端可能指向已看不見的更前一代)
11. 幽靈只有頭頂可以站: 角色下落時(垂直速度 ≥ 0)腳底穿過幽靈頭頂、且水平有重疊, 就站在幽靈頭上。幽靈的其他部位不擋角色
12. 站在幽靈頭上時, 角色跟著幽靈移動(水平位移相加, 腳底每幀貼齊幽靈頭頂, 幽靈上升、下降、被鉤爪拉動或甩飛都跟著); 可以從幽靈頭上起跳; 水平走出幽靈頭頂範圍即離開
13. 幽靈循環從最後一幀跳回第 0 幀時, 站在它頭上的角色不跟著瞬移, 改為進入空中狀態
14. 前一代路線: 畫面畫出當前幽靈整條紀錄的路線(每幀幽靈中心連成線), 並標出幽靈目前播到哪一點
15. **鉤爪次數三代共用(新)**: 一局開始時全隊共有 2 次鉤爪; 任何一代用掉就少一次, 換代不補; 只有整關重來才回到 2 次。HUD 隨時顯示剩餘次數
16. 可鉤條件: 幽靈存在、角色中心與幽靈中心距離 ≤ 鉤爪範圍、全隊剩餘次數 > 0。條件成立時幽靈顯示「可鉤」發光
17. 按鉤爪鍵且可鉤: 扣 1 次; 角色在拉動時間內被拉到幽靈頭頂(目標追著幽靈當下位置), 拉動期間不受重力、不能操控。拉動結束瞬間, 若幽靈當下在空中(紀錄中未著地)獲得向上「強甩速度」, 若幽靈著地獲得「弱甩速度」(弱甩一樣扣次數); 水平速度歸零, 之後在空中可左右移動
18. 按鉤爪鍵但不可鉤: 不發生任何事, 不扣次數
19. 拉動中若幽靈循環跳回第 0 幀, 鉤爪中斷, 角色以當下位置進入空中狀態(次數已扣)
20. 開關被壓住的條件: 角色或場上的幽靈處於著地狀態, 腳底與開關所在平台表面同高, 且水平與開關有重疊
21. 門在開關被壓住期間開啟; 開關放開後經過「關門延遲」才關上。門關著時是實心牆, 角色無法穿過也跳不過
22. 門要關上的那一刻若角色與門重疊, 門延後到角色離開後才關
23. 「整關重來」: 回到第 1 代開局, 清空所有紀錄, 鉤爪回到 2 次。沒有其他任何重來方式
24. 角色碰到終點旗即過關
25. 過關後進入回放: 第 1、2 代的紀錄與過關那一代從出生到過關的紀錄, 同時從第 0 幀開始以幽靈播放並循環; 三代都顯示(含鉤索), 門與開關照回放中的壓住狀態開關; 回放時不畫路線
26. 第 3 代死亡即失敗

設計意圖(給 RD 驗算用, 不給玩家看):
- 一般跳 168 px; 踩頭 +56; 搭著跳躍中的幽靈再在最高點跳, 最多 56+168+168=392 px。兩段平台高差都是 420 px, 只能靠鉤騰空幽靈(從它頭頂甩 300 px, 幽靈離地 ≥ 64 px 時鉤才夠)
- 第 1 代無幽靈可鉤, 必死; 它要在地上 x 60~440 之間跳一次(太靠左會被甩到尖刺上)
- 第 2 代鉤第 1 代上平台一用掉 1 次; 若第一下鉤到著地幽靈(弱甩)或鉤得太低, 再補鉤就把第 3 代的份用掉 → 第 3 代上不了平台二(H22 的負面情境)。第 2 代無論如何上不了平台二(地上的幽靈最高只甩到腳底 y≈676), 它要在平台一 x 240~440 跳一次給第 3 代鉤, 然後踩住開關
- 第 3 代上平台一的省錢做法: 趁第 2 代幽靈在地上時跳上它的頭, 被它那一鉤一起帶上去; 若改用鉤爪上平台一, 就沒有次數上平台二。另一條較難的路: 在第 2 代幽靈被甩到高點時鉤它, 可直接飛上平台二
- 門頂 y=140; 從平台二跳最高腳底 y≈192, 鉤爪甩最高腳底 y≈256, 都過不了門

## 勝負與結束
- 勝利: 任一代角色碰到終點旗 → 顯示過關字樣並播放三代同時回放, 按空白鍵回到第 1 代開局
- 失敗: 第 3 代死亡 → 顯示失敗畫面, 按空白鍵回到第 1 代開局
- 開啟網頁先顯示說明頁, 翻完進入遊戲

## 範圍邊界
- 只有一關, 無難度曲線、無計分
- 無怪物; 無「這一代重來」、無重錄上一代, 只有整關重來
- 鉤爪只能鉤幽靈, 不能鉤平台或牆; 場上沒有可撿的鉤爪道具, 次數只在 HUD 上
- 只有一組開關與門
- 無音效、無存檔、無慢動作
