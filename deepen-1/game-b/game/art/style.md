# 共鉤 美術規格(style.md)

> index.html 必須宣告 `<meta charset="utf-8">`, 否則 art.js 的中文字會變亂碼。
> art.js 以 `<script src="art/art.js">` 一般 script 載入(非 module), 產生全域 `window.Art`。

## 邏輯畫布尺寸

720 × 1280(直式)。HUD 佔 y 0~100, 遊戲世界座標與畫布座標相同, 不捲動。

## 形狀語言

圓角、扁平、深色描邊襯底; 角色是圓角豆形 + 兩條短腿, 場景是直角塊; 「實心 = 實體 / 能操作」、「半透明 = 重播」、「點線 = 不在場 / 可通過」。

## 理念落實

- P0 辨識度先於好看: 玩家與幽靈走兩條通道 — 實心金黃 vs 半透明藍 + 頭頂實線踏板; 尖刺是全畫面唯一的紅色三角。
- P1 視覺權重跟著決策迫切度: 「現在能鉤」是最亮的元素(淡青外光 + 脈動), 路線只用 45% 細線退到背景之上一層; 背景星點靜止低亮。
- P2 規則上存在就要畫出來: 幽靈只有頭頂能站 → 頭頂畫一條全寬實線踏板; 單向平台下半畫斜紋半透明表示可穿過; 全隊鉤爪次數常駐 HUD; 坑畫成往下漸暗帶紅; 所有物件的實體邊緣畫在判定框上, 可鉤外光剪裁在頭頂以下, 不讓頭頂看起來比判定高。
- P3 一本字典: 淡青只代表鉤爪(鉤索 / 可鉤 / HUD 圖示 / 被拉中外框); 洋紅只代表開關-門連動; 說明頁全部呼叫遊戲內同一套畫法, HUD 小人圖示也用「實心金黃 = 你、半透明藍 + 頂線 = 幽靈、點線 = 看不見」同一組長相。
- P4 關鍵區分兩條通道: 可鉤 = 顏色(藍 → 淡青)+ 動態(脈動外光)+ 外框加粗; 開關 = 高度(凸起 vs 壓平)+ 亮度; 門 = 實心門板 vs 點線框; 鉤爪圖示 = 亮青實線 vs 暗色虛線圈。
- P7 每個元素掙得版面: 角色上只標代數小字(回放時三隻幽靈要分得出); 平台、開關、門不配名稱字樣。
- P9 以最混亂那刻驗收: 過關回放時三代幽靈 + 鉤索 + 門開關同時動, 鉤索帶 7px 深色襯線、幽靈帶代數, 過關字卡半透明且只佔 y 560~710。
- P13 事件排隊: 全作只有三種事件字樣(換人 / 過關 / 失敗), 依 phase 互斥, 不會同時出現。
- P15 回饋強度與份量: 換人只是一行字, 過關是帶框字卡, 失敗是全畫面暗幕。
- P17 進度類圖形與數字分工: 鉤爪次數只用可數圖示(沒有數字), 代數用小人圖示表狀態、文字給「第幾人 / 共幾人」。
- P18 重要資訊不能只閃一下: 鉤爪剩餘與誰是幽靈常駐 HUD。
- P19 資訊貼著物件: 可鉤直接長在幽靈身上(外光 + 框色), 不另掛圖示; 代數寫在角色肚子上。
- P21 示意圖選分岔例子: 第 2 頁「跳不上去 ✗ / 掉進坑 ✓」並排; 第 5 頁兩格都發光(規則上地上的幽靈一樣可鉤), 只差「幽靈在地上 vs 在半空」, 結果一個沒上平台 ✗、一個上了 ✓; 第 7 頁兩格只差有沒有人踩。

## 物件表

所有物件函式自帶 `ctx.save()/restore()`。x/y 為物件左上角(drawHook、drawGhostPath 除外)。

| 物件 | 函式 | state 欄位 | 各狀態視覺 |
|---|---|---|---|
| 背景 | `drawBackground(ctx)` | — | 夜空漸層 + 靜止星點; 已畫好坑(x 600~720, y 1200~1280)的漸暗紅底 |
| 平台 | `drawPlatform(ctx, {x, y, w, h})` | x, y, w, h | **h ≥ 48 畫成實心地面**(表層亮邊 6px); **h < 48 畫成單向平台**: 頂板 8px 實心亮色 + 下方斜紋半透明 |
| 尖刺 | `drawSpike(ctx, {x, y, w})` | x, y, w | 底座 4px 金屬 + 紅色三角(每 12px 一根), 高固定 24 |
| 開關 | `drawPlate(ctx, {x, y, pressed})` | x, y, pressed | false: 凸起暗洋紅鈕 + 亮洋紅框 + 向下小箭頭; true: 壓平成 4px 亮洋紅條並發光 |
| 門 | `drawGate(ctx, {x, y, open})` | x, y, open | false: 實心深色門板 + 三根直條 + 暗洋紅鎖燈; true: 只剩點線框 + 頂端 12px 亮洋紅收起的門板 + 底檻 |
| 終點旗 | `drawGoal(ctx, {x, y})` | x, y | 旗桿 + 亮綠旗面(帶星, 微幅飄動) |
| 幽靈路線 | `drawGhostPath(ctx, {points, progress})` | points: [{x,y}] 碰撞框中心; progress: 整數索引 | 深色襯線 + 45% 藍細線; 起點小方塊; progress 那一點畫白圈藍心標記 |
| 幽靈 | `drawGhost(ctx, {x, y, facing, state, gen, hookable})` | facing 1/-1; state idle/run/air/hook; gen 1~3; hookable 布林 | 半透明藍身 + 實線框 + **頭頂全寬實線踏板**; 肚子寫 gen; 姿勢同玩家; **hookable=true: 框與踏板換淡青、身體淡青填色、左右與下方淡青脈動外光(頭頂以上不發光)** |
| 鉤索 | `drawHook(ctx, {x1, y1, x2, y2})` | 被拉者中心 → 被鉤幽靈頭頂中心 | 深色襯線 + 淡青發光線 + 終點(x2,y2)雙爪與白點 |
| 玩家 | `drawPlayer(ctx, {x, y, facing, state, gen})` | facing 1/-1; state idle/run/air/hook/dead; gen 1~3 | 實心金黃豆形 + 淡白框, 眼睛偏向 facing; idle 雙腿並排; run 雙腿交錯擺動; air 腿收短外張、眼睛拉長; hook 外框換淡青 + 朝面向側舉手; dead 灰色身體 + X 眼 + 腿攤平; 肚子寫 gen(gen 為 0/空則不寫) |
| HUD | `drawHud(ctx, {gen, maxGen, phase, hookLeft, hookMax})` | phase: play/dying/win/lose | 見下 |
| 說明頁 | `drawGuidePage(ctx, {page})` | page 0~7 | 全畫面自繪(含背景), 不需先畫其他東西 |

HUD 細節(y 0~100 自帶底色, 最後畫):
- 左: maxGen 個小人圖示 — 當前代 = 實心金黃, 上一代 = 半透明藍幽靈, 更早的 = 點線(已消失), 還沒輪到 = 暗框; phase=win 時三個都畫成幽靈。旁邊「第 N 人 / 3」
- 右: 「全隊鉤爪」+ hookMax 個鉤爪圖示, 前 hookLeft 個亮青, 其餘暗色虛線圈(用掉)
- 下緣一行操作提示
- phase=dying: y≈132 一行「倒下了, 換下一個人」(gen == maxGen 時只寫「倒下了」)
- phase=win: y 560~710 半透明帶框字卡「過關! / 三人合力回放中 / 按空白鍵重來」, 底下回放照畫
- phase=lose: y 100 以下全畫面暗幕 +「失敗 / 三個人都倒下了 / 按空白鍵重來」

### 繪製層級(由下到上)

drawBackground → drawPlatform(全部)→ drawSpike → drawPlate → drawGate → drawGoal → drawGhostPath(回放時不畫)→ drawGhost → drawHook(鉤索畫在幽靈之上、玩家之下)→ drawPlayer → drawHud
