# 美術經驗提案

## 合併到「經驗 > 交付自查」的「發布用的圖示 / 橫幅沿用遊戲內的全畫面繪製函式…」那一條(加一段「同類」)

- 同類(接力吉尼 發布輪建置設計判斷, 非老闆回饋, 不算升格證據; 角色身上自帶的字): 沿用的不是全畫面函式、而是單一角色函式, 字一樣長在角色身上(該作: 玩家 / 幽靈胸口的代數數字、可鉤幽靈旁的 Z 鍵帽與「等它跳」小牌), 放大 6~11 倍後變成圖示正中央最大的字, 橫幅也多出一串數字 → 只想到「場景函式帶字」, 角色函式的字藏在狀態欄位裡(代數有值就畫、可鉤為真就畫鍵帽) → 沿用角色函式前, 先搜它的每個畫字 / 鍵帽分支是由哪個 state 欄位觸發, 繪製頁一律把這些欄位傳成不觸發的值(該作: 代數不傳、可鉤傳 false); 自測的文字記錄照樣會抓到, 圖示 0 筆、橫幅只剩遊戲名才算過(不掛理念: 屬交付流程; 玩家看到的後果是 P7)
