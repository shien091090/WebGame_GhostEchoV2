# 幽影接力 美術規格(polish-2 / 打磨版第 2 輪: 六關, 能力解鎖制)

> index.html 必須宣告 `<meta charset="utf-8">`, 否則 art.js 的中文字串在 file:// 下會變亂碼。
> 用法: `<script src="art/art.js"></script>` 後取用全域 `window.Art`。全部函式自帶 save / restore。
> 沿用 polish-1 的色票、形狀語言與物件畫法。本版變動: **移除** 鑰匙、鎖(drawKey、drawLock、hasKey、HUD 鑰匙格); **新增** drawButton、drawCrusher、drawPlatform 的 `solid`、幽靈可鉤時的 Z 鍵帽、瞄準時角色旁的「Z 射出 / X 取消」; HUD 不再畫瞄準文字; 說明頁全畫布模式的底部提示改成可前後翻頁; 關卡卡片 newThing 'key' 換成 'button'; 鉤爪解鎖頁改成兩格。

## 邏輯畫布尺寸

720 × 1280。HUD 佔上方 y 0~100(drawHud 自己畫底板), 遊戲區 y 100~1280。

色相分配: 紅 0°(危險)、**橘 30°(按鈕 + 壓板)**、金 46°(終點)、黃綠 90°(鉤爪)、青 186°(升降台)、淡藍 221°(幽靈, 低飽和半透明)、洋紅 289°(門)。紅只給危險。

**壓板色的取捨**: 色環上已沒有遠離所有語意色的空檔; 橘離會同框的開關色(青、洋紅)最遠, 跟鉤爪的黃綠也分得開(幽靈踩按鈕時會疊在按鈕上)。橘和紅、金是相鄰色, 所以另外靠形狀與明度分開: 壓板本體是**暗棕**大塊, 橘只出現在兩側亮邊與下緣斜紋帶, 底下的紅尖刺本來就屬於壓板(危險部位); 終點旗是小面積金色旗面 + 星, 與 360 寬的暗色柱子不會讀成同一個東西。試玩若把壓板讀成「金色」, 優先把斜紋帶的橘往暗調, 不動危險紅與終點金。

## 形狀語言

圓角方塊角色、扁平無漸層的場景塊; 狀態靠「亮色 vs 暗色 + 實心 vs 虛線」切換; 「實心擋路」只有地面材質一種長相(地面、實心平台、牆); 「會開的東西」開著時只剩「虛線框 + 上下框頭」; 「按鈕 / 壓板」這一組共用斜紋帶記號; 按鍵提示一律是同一種淺色鍵帽; 所有文字帶深色描邊。

## 理念落實

- P0: 玩家 = 實心奶白 + 深外框; 幽靈 = 同剪影, 半透明淡藍 + 虛線外框; 危險只用紅(含壓板底面尖刺); 每種可互動物件都有專屬色 + 專屬記號(升降台開關 ↑ / 門開關直條 / 按鈕圓頂 + 斜紋 / 翹翹板 ↓↑)。
- P1: 最顯眼的是「現在可以鉤」(鉤爪色粗框 + Z 鍵帽)、瞄準箭頭、壓板倒數量條; 路線、背景網格、升降台軌道壓在低不透明度。壓板本體用暗棕, 讓橘色只落在斜紋帶與量條附近, 不讓 360 寬的大柱子整片搶眼。瞄準提示框畫在箭頭**底下**, 箭頭永遠在最上層。
- P2: 幽靈「只有頭頂可站」畫成頭頂一條實線; 實心平台用地面材質、平整底緣, 單向平台保留下緣鋸齒(從下可穿); 壓板倒數用量條常駐軌道(沒在倒數時是空軌), 讓「這根柱子有計時」一直看得到; 升降台行程畫成背景軌道(只在第 4 關)。
- P3: 鉤爪色只代表鉤爪系統, 壓板色只代表按鈕與壓板; 開關與受控物件同色同記號; 鍵帽全遊戲同一樣式(HUD、幽靈旁 Z、角色旁 Z / X、說明頁); 說明頁、關卡卡片、解鎖頁、全破畫面的物件全部呼叫遊戲內函式並給規則上成立的 state。
- P4: 按鈕 vs 開關踏板: 顏色(橘 vs 青 / 洋紅)+ 外形(圓頂 vs 平板); 實心平台 vs 單向平台: 材質明度(暗地面 vs 亮平台)+ 底緣(平整 vs 鋸齒); 翹翹板兩端靠明度 + 箭頭方向; 玩家與幽靈靠不透明度 + 外框線型。
- P7: HUD 只放代數、關卡、已解鎖的能力、按鍵提示和靜音; 沒解鎖的能力整塊不畫。瞄準提示從 HUD 拿掉(已改畫在角色旁), 不留兩份。
- P9: 線類元素(路線、鉤索、瞄準線、箭頭)都有深色襯底; 鍵帽與瞄準提示框自帶深色底板, 壓在三代回放或壓板上照樣讀得到。
- P13: 過關 / 失敗面板只有一塊, 不和其他事件疊。
- P15: 吹哨波紋(全場重要事件)是場上唯一的外擴大環; 鉤索只有 0.15 秒細線; 翹翹板擺動只在發射端上方多三條短線; 壓板警告閃爍只在最後 0.3 秒。
- P17: 蓄力: 箭頭長度 = 會飛多遠, 蓄力環 = 離滿還差多少。壓板: 量條長度 = 剩多久, 量條上每 0.3 秒一格刻度。
- P18: 鉤爪次數常駐 HUD; 代數用三個小人常駐。
- P19: 按鍵提示貼著物件: 可鉤時 Z 鍵帽貼在幽靈框外右上角; 瞄準時「Z 射出 / X 取消」貼在角色頭頂; 壓板倒數條畫在壓板本體下緣、玩家鑽過去時視線所在處。
- P21: 說明第 2 頁並排「跳不上(叉)」與「掉坑(勾)」; 第 5 頁畫出 2 號幽靈腳下看不見的 1 號虛線輪廓; 起跑哨解鎖頁並排吹哨前後, 舊位置留虛線輪廓。

### drawHud 細節(版位固定, 沒解鎖的區塊留空、不移位)

- 左 x 16~200: 「第 N 代 / 3」+ 三個小人: 目前代 = 玩家樣、上一代 = 幽靈樣、更早 = 虛線消失、未來 = 空框
- x 222 中心: 「關卡」+「L / 6」
- x 290~380: hookUnlocked 時才畫: Z 鍵帽 + 「鉤爪」+ hookMax 格, 剩的實心, 用掉的虛線暗格
- x 455~530: whistleUnlocked 時才畫「C 吹哨」(aiming 時淡到 35%, 瞄準中 C 無效)
- x 557~630: 「R 重來」
- 右上 x 672~708: 喇叭(muted 時灰身 + 斜線)+ 下方 M 鍵帽
- **aiming=true**: 只在遊戲區四周畫冷色霧框 + 四角括號 + 右上暫停符號(時間停了); **不畫任何文字**, 「Z 射出 / X 取消」由 drawAim 畫在角色旁
- phase=dying 且 gen<maxGen: HUD 下方小字「第 N+1 代準備出發…」
- phase=win: 畫面中段(y 520~720)金框面板「過關!/ 三代合力回放中 / 空白鍵 下一關」; 回放照常可見
- phase=lose: 遊戲區全蓋暗幕 + 「失敗 / 三個人都沒摸到旗子 / 空白鍵 再試一次」

### 說明頁分工(drawGuidePage)

- **RD 傳 `{page, x, y, w, h}`(建議)**: 美術只在 (x, y, w, h) 框內畫示意圖, 裁在框內; 不畫背景、頁標題、說明文字、頁碼、翻頁提示。示意圖設計比例 640 × 760, 等比縮放置中進框(建議框 `x 40, y 300, w 640, h 760`)。圖內只有物件旁的短標籤(「你」「終點旗」「幽靈」「1 號」等)。
- **只傳 `{page}`**(interface.json 的寫法): 畫滿整張畫布, 含背景、標題、說明文字、示意圖、頁碼點(y 1120)、底部翻頁提示(y 1210): 第 1 頁「[→] / [空白鍵] 下一頁」; 第 2~4 頁「[←] 上一頁   [→] / [空白鍵] 下一頁」; 第 5 頁「[←] 上一頁   [→] / [空白鍵] 開始遊戲」。這時 RD 不要再畫任何字。
- 兩種模式擇一, 不要同時用。第 1 頁的 ←→ / 空白鍵 / R 鍵帽與角落 M + 喇叭是 guide.md 指定「標在角色身旁」的圖內標示, 由美術畫在框內; RD 不要重畫。
