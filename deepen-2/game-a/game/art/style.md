# 翹翹板接力 美術規格

> index.html 必須宣告 `<meta charset="utf-8">`, 否則 art.js 裡的中文(HUD、說明頁)會變亂碼。
> 載入方式: `<script src="art/art.js"></script>`(非 module), 之後用 `window.Art`。

## 邏輯畫布尺寸

720 × 1280(直式)。HUD 佔上方 y 0~100; 遊戲區 y 100~1280。座標全部是遊戲世界座標, 不捲動。

## 形狀語言

扁平幾何、角色圓角、機關方角; 「可站的邊」一律是一條亮色實心頂緣, 「可穿過的邊」一律是虛線。

## 理念落實

- P0 辨識度先於好看: 每類物件獨佔一個色相(紅尖刺 / 綠升降 / 藍門 / 黃鉤爪 / 淡紫幽靈 / 奶油角色 / 木色翹翹板), 背景只有極淡點陣
- P1 視覺權重跟著決策迫切度: 最亮的是此刻能做決定的東西 — 可鉤的幽靈(黃外光)、瞄準箭頭; 路線降到 0.6 不透明點線, 背景與地面最暗
- P2 規則上存在的東西畫面上就要存在: 幽靈頭頂畫一條實心亮條(只有頭頂能站); 單向平台底面畫虛線(下方可穿過); 升降台畫出整段行程軌道; 門開著時留門楣與虛線框; 物件實心部分都在判定框內
- P3 一個意義一種長相: 黃色只代表鉤爪(HUD 次數、可鉤發光、瞄準、鉤索、暫停框); 淡紫半透明只代表幽靈(含路線、HUD 上一代圖示、說明頁); 說明頁全部呼叫遊戲內畫法
- P4 關鍵區分走兩條通道: 角色 vs 幽靈 = 色相 + 實心 / 半透明虛線框; 落點端 vs 發射端 = 明度(深 / 亮)+ 箭頭方向(▼ / ▲); 開關放開 vs 壓住 = 高度(凸起 / 薄條)+ 亮度(暗 / 發光); 門開 vs 關 = 實心條紋 / 虛線空框
- P7 每個元素掙得版面: 角色身上不寫代數(場上同時只有一個角色一個幽靈, HUD 已給); 路線不加箭頭、不加終點標記; 鉤爪蓄力不另畫蓄力條(箭頭長度就是)
- P9 以最混亂的一刻驗收: 過關回放三代幽靈 + 鉤索同時在畫面上, 幽靈仍靠頭頂亮條與虛線框分得出, 鉤索帶深色襯底, 壓在任何東西上都讀得到
- P13 事件排隊: 本作 HUD 一次只顯示一個狀態訊息(瞄準提示 / 換人 / 過關 / 失敗互斥), 不疊
- P15 回饋強度和份量成正比: 開關壓下 = 小外光; 翹翹板觸發 = 板身擺動 + 發射端噴白線; 鉤爪彈出 = 整條鉤索 + 角色速度線; 過關 / 失敗 = HUD 整條換字 / 全畫面遮罩
- P17 進度圖形與數字分工: 蓄力只有圖形(箭頭長度 = 速度), 蓄滿那一刻箭頭加白芯與外光作為「達成」的獨立回饋; 鉤爪次數用可數圖示不寫數字
- P18 重要資訊不只存在一瞬間: 鉤爪剩餘次數常駐 HUD(用掉的變暗虛線圈); 目前第幾人與上一代 / 更早代的可見性常駐 HUD
- P19 資訊貼著物件: 可鉤直接是幽靈本體發光, 不另掛圖示; 升降台的方向箭頭畫在升降台身上; 開關用與受控物件同色
- P21 示意圖選分岔例子: 第 2 頁並排「跳不上(差距 + 叉)」與「掉坑(勾)」; 第 7 頁並排「自己落點端、發射端沒人(叉)」與「幽靈落下、你飛起(勾)」; 第 8 頁 2 號幽靈腳下畫出看不見的升降台虛線, 對照實際停在底部的升降台

## 繪製層級(由下而上)

drawBackground → drawPlatform(全部)→ drawLift → drawSpike → drawPlate(兩個)→ drawSeesaw → drawGate → drawGoal → drawGhostPath → drawGhost(回放時三隻)→ drawHook → drawPlayer → drawAim → drawHud

## 物件表

所有函式簽章 `drawXxx(ctx, state)`, 各自 save/restore。x, y 為左上角(drawLift 的 y 為頂面; drawHook / drawGhostPath / drawAim 例外)。

| 物件 | 函式 | state 欄位 | 各狀態視覺 |
|---|---|---|---|
| 背景 | `drawBackground(ctx)` | — | 深藍漸層 + 極淡點陣, 整張 720×1280 |
| Platform | `drawPlatform(ctx, {x, y, w, h})` | x, y, w, h | h ≥ 48 視為地面: 實心厚塊 + 灰白頂緣; h < 48 視為單向平台: 亮頂緣 6px 內 + 底面虛線(下方可穿) |
| Spike | `drawSpike(ctx, {x, y, w})` | x, y, w | 紅色三角一排(每約 15px 一根)+ 暗紅底座, 無狀態 |
| Plate | `drawPlate(ctx, {x, y, pressed, kind})` | pressed: bool; kind: 'lift' \| 'gate' | 顏色: lift 綠 / gate 藍。放開 = 暗色凸起鈕佔滿 12px 高、亮頂、鈕面小記號(lift ▲ / gate ■); 壓住 = 只剩底部 4px 亮條 + 外光。兩端各有一根同色短柱標出開關範圍 |
| Lift | `drawLift(ctx, {x, y, active})` | y: 頂面 780~1200; active: bool | 常駐淡綠虛線軌道(x+8 與 x+112, y 780~1224)。active = 亮綠 + 外光 + 白色 ▲▲▲; 非 active 且 y < 1200(下降中 / 停在半空)= 暗綠 + 暗色 ▼▼▼; 非 active 且在底 = 暗綠無箭頭 |
| Gate | `drawGate(ctx, {x, y, open})` | open: bool | 關 = 實心藍 + 斜條紋 + 淡框; 開 = 0.12 淡藍填 + 藍虛線框。兩者都有頂端 6px 門楣 |
| Seesaw | `drawSeesaw(ctx, {x, y, tilt})` | tilt: 0~1 | 支點三角在 x+100。左 80px 落點端 = 深木色 + 白 ▼▼; 中 40px 板身; 右 80px 發射端 = 亮木色 + 深 ▲▲。tilt 時整片繞支點逆時針轉 tilt × 0.14 rad(約 8°), 發射端上方冒白線(長度、不透明度隨 tilt) |

| Ghost | `drawGhost(ctx, {x, y, facing, state, gen, hookable})` | facing: 1 / -1; state: idle / run / air / launch; gen: 1~3; hookable: bool | 半透明淡紫身體 + 虛線框 + 頭頂 5px 實心亮條; 眼罩在朝向側。idle 雙腳並立; run 跨步; air 縮腳; launch 縮腳 + 腳下淡紫速度線。hookable = 黃色外光 + 黃色 4px 外框。gen 不改外觀 |
| Hook | `drawHook(ctx, {x1, y1, x2, y2})` | 角色中心 → 幽靈中心 | 黃線寬 3 + 深色襯底, 終點畫爪頭 |
| Player | `drawPlayer(ctx, {x, y, facing, state, gen})` | state: idle / run / air / aim / launch / dead | 實心奶油色身體 + 深框, 眼罩在朝向側。idle / run / air 腳形同幽靈; aim = 縮腳 + 黃色 3px 內框; launch = 縮腳 + 腳下黃色速度線; dead = 灰色、壓扁到下半(y+18 起)、X 眼。gen 不改外觀 |

| 說明頁 | `drawGuidePage(ctx, {page})` | page: 0~7 | 整張畫布: 標題、本頁文字、示意圖、頁碼點、底部「空白鍵 下一頁 / 開始遊戲」 |

### HUD 細節(y 0~100 底板)

- 左: maxGen 個小人(縮 0.75)排一列, 下方標號 1~3。目前那代 = 實心角色(dying / lose 時為死亡樣)、上一代 = 幽靈樣、更早 = 淡紫虛線輪廓(已消失)、未來 = 灰框; 旁邊「第 N / 3 人」
- 中: 「鉤爪」+ hookMax 個鉤爪圖示, 前 hookLeft 個實心黃, 其餘暗虛線圈
- aiming = true: 中右黃色提示條「‖ Z 彈出 / X 取消」, 並在遊戲區外圍(3,103,714,1174)畫 6px 黃框表示時間停住
- phase = dying 且 gen < maxGen: 中右「換下一個人…」
- 右: 「R 重來」常駐
- phase = win: 整條 HUD 換成「過關!/ 三代合力回放」+「空白鍵 重來」, 不遮遊戲區(回放照常畫在下方)
- phase = lose: HUD 照常, 遊戲區蓋 0.8 黑罩 +「失敗 / 三個人都倒下了 / 空白鍵 重來」
