# 翹翹板接力(幽靈落下, 把你彈上去)

## 概述
走到終點前必須先死, 死掉的自己變成不斷重演的幽靈, 下一個自己踩它、搭它、鉤它, 讓它守住開關, 三個人內摸到旗子。這款的新機制是**翹翹板**: 平台一上有一座翹翹板, 只要有人(含幽靈)從空中落到「落點端」, 站在另一頭「發射端」的角色就會被高高彈起。自己一個人不可能同時踩兩頭, 一定要前一代的幽靈落下來「送你上去」; 玩家要看著前一代接下來的路線, 預先站好位, 等它落下。
本款同時套用使用者提案的兩項改動: 前一代路線只畫接下來 5 秒、鉤爪改為瞄準式(時間暫停 → 看方向與力道 → 彈出或取消)。
驗證假設: H27 H28 H29 H30(並沿用 H03 H05 H07 H11 H12 H13 H14 H18 H23)

## 核心循環
第 1 代站上升降台開關守著, 替第 2 代開電梯, 然後死去 → 第 2 代搭電梯上平台一, 先在翹翹板落點端跳一下(替第 3 代發射), 再去踩住門開關 → 第 3 代看不到第 1 代, 搭第 2 代幽靈的便車上平台一(它像在坐一台看不見的電梯), 站到發射端等第 2 代幽靈落下, 被彈上平台二, 趁門開衝向旗子 → 過關看三代合力回放。

## 規則
1. 單一畫面、單一關卡, 不捲動。座標以畫布左上為原點, y 向下
2. 角色左右走、跳躍; 受重力, 落地才能起跳(地面、平台、升降台、翹翹板、幽靈頭頂都算落地)
3. 地面為實心; 空中平台與升降台為單向平台: 從下方可穿過, 從上方落下時會站上去
4. 角色掉出畫面下緣即死亡; 碰到尖刺即死亡
5. 共三代角色, 第 1 代開局出生在出生點
6. 每代從出生到死亡的每一幀都被記錄(60 幀/秒): 位置、朝向、動作狀態、是否著地、鉤索兩端(只在彈出後的鉤索顯示時間內才有)。瞄準暫停期間時間不前進、不記錄。錄製達 60 秒時該代自動死亡
7. 某代死亡後播放 0.6 秒死亡演出, 接著下一代在出生點出生; 升降台、門、翹翹板回到初始狀態後再依當下狀況運作
8. 新一代出生的同一幀, 上一代的紀錄從第 0 幀開始以「幽靈」重播; 播完最後一幀後立刻從第 0 幀重新開始, 無限循環
9. 場上只存在「上一代」的幽靈: 操控第 2 代時只有第 1 代幽靈; 操控第 3 代時只有第 2 代幽靈, 第 1 代幽靈完全消失(不顯示、不可踩、不可鉤、不壓開關、不觸發翹翹板)
10. 幽靈不受尖刺、坑洞、門、升降台、翹翹板影響, 純粹照紀錄重播; 紀錄中帶鉤索的幀, 幽靈連同它的鉤索一起顯示
11. 幽靈只有頭頂可以站: 角色下落時(垂直速度 ≥ 0)腳底穿過幽靈頭頂、且水平有重疊, 就站在幽靈頭上。幽靈的其他部位不擋角色
12. 站在幽靈頭上時, 角色跟著幽靈移動(水平位移相加, 腳底每幀貼齊幽靈頭頂, 幽靈上升或下降都跟著); 可以從幽靈頭上起跳; 水平走出幽靈頭頂範圍即離開
13. 幽靈循環從最後一幀跳回第 0 幀時, 站在它頭上的角色不跟著瞬移, 改為進入空中狀態

### 前一代路線(5 秒)
14. 畫面畫出當前幽靈「從目前這一幀起、接下來 300 幀(5 秒)」的紀錄位置(每幀幽靈中心連成線), 單一顏色。紀錄剩不到 300 幀時接回第 0 幀繼續畫, 但總長最多一整圈; 接回處斷開成兩段, 不連線。不畫已經走過的部分、不分色、不加預影

### 鉤爪(瞄準式)
15. 每代有 2 次鉤爪; 下一代出生時重新給 2 次
16. 可鉤條件: 幽靈存在、角色中心與幽靈中心距離 ≤ 鉤爪範圍、本代還有次數。條件成立時幽靈顯示「可鉤」發光
17. 按 Z 且可鉤 → 進入「瞄準」: 時間暫停(角色、幽靈、升降台、門、翹翹板、關門延遲、錄製全部停住)。按 Z 但不可鉤: 不發生任何事
18. 瞄準中畫出: 從角色中心到幽靈中心的虛線(彈出方向); 從角色中心沿同方向的箭頭, 長度 = 當下彈出速度 × 0.3 秒。蓄力值從 0 開始依真實時間增加, 1 秒到滿後停在滿。彈出速度 = 速度上限 × (0.3 + 0.7 × 蓄力值); 速度上限看幽靈當下狀態: 在空中(紀錄中未著地)用「騰空上限」, 著地用「著地上限」
19. 瞄準中再按 Z → 彈出: 扣 1 次, 時間恢復; 角色速度直接設為「方向 × 彈出速度」並離開地面或幽靈頭頂。彈出後的「彈射時間」內左右鍵無效、保留水平速度, 之後恢復一般操控; 全程受重力。撞到實心牆或關著的門時水平速度歸零。彈出後在「鉤索顯示時間」內畫鉤索: 角色中心 → 被鉤幽靈當下中心
20. 瞄準中按 X → 取消: 不扣次數, 時間恢復, 角色維持暫停前的狀態
21. 瞄準中只有 Z、X、R 有作用; 其他按鍵無效

### 開關、升降台、門
22. 開關有兩個: 升降台開關(在地面)、門開關(在平台一)。開關被壓住的條件: 角色或場上的幽靈處於著地狀態, 腳底與開關所在平台表面同高, 且水平與開關有重疊
23. 升降台開關被壓住期間, 升降台以「升降速度」往上移, 到最高點停住; 放開後以同速往下移, 回到最低點停住。站在升降台上的角色跟著上下移動。升降台最低點時頂面與地面齊平, 下方地面一直存在
24. 門在門開關被壓住期間開啟; 開關放開後經過「關門延遲」才關上。門關著時是實心牆, 角色無法穿過也跳不過
25. 門要關上的那一刻若角色與門重疊, 門延後到角色離開後才關
26. 每個開關與它控制的物件要用同一種顏色標示

### 翹翹板(新)
27. 翹翹板嵌在平台一上, 有兩端: 「落點端」與「發射端」, 兩端頂面都與平台一表面齊平, 可以正常站、走過
28. 觸發: 角色或場上的幽靈「從空中落到落點端上」——上一幀未著地、這一幀著地, 腳底與平台一同高且水平與落點端有重疊。幽靈以紀錄判斷(比較紀錄中相鄰兩幀; 循環從最後一幀接回第 0 幀不算)
29. 觸發的那一幀, 所有「著地站在發射端上」的角色(腳底與平台一同高、水平與發射端重疊)垂直速度設為向上「彈射速度」、水平速度歸零, 進入空中狀態, 之後可正常左右移動。幽靈站在發射端上不受影響
30. 觸發時翹翹板播放「落點端壓下、發射端翹起」的擺動演出 0.3 秒後回平; 沒人站在發射端時也照樣擺動。演出中仍可再次觸發

### 結束
31. 「整關重來」: 回到第 1 代開局, 清空所有紀錄。沒有其他任何重來方式
32. 角色碰到終點旗即過關
33. 過關後進入回放: 第 1、2 代的紀錄與過關那一代從出生到過關的紀錄, 同時從第 0 幀開始以幽靈播放並循環; 三代都顯示(含鉤索), 兩個開關、升降台、門、翹翹板照回放中的狀態運作; 回放時不畫路線
34. 第 3 代死亡即失敗

- 另解: 第 1 代在地上跳, 第 2 代鉤它上平台一(用掉 1 次)
- 第 2 代上不了平台二: 第 1 代幽靈永遠在地上, 不會觸發翹翹板, 從平台一鉤它方向朝下。它要先在落點端跳一下(替第 3 代觸發), 再踩住門開關不放(之後可走進左邊尖刺結束)。落點端與門開關相鄰, 跳完往左走 20 px 就到
- 第 3 代看不到第 1 代, 升降台不會升; 要先跳上第 2 代幽靈的頭(在地上時頭頂離地 56 px), 被它載上平台一, 再趕在它跳落點端之前站上發射端。第 2 代跳落點端的時機越晚, 第 3 代越從容——這是「替下一代設計」的空間
- 第 3 代也可以改鉤第 2 代在落點端的那一跳(站在它正下方附近), 用鉤爪上平台二; 兩種解法都成立
- 門頂 y=140; 從平台二跳最高腳底 y≈192, 被翹翹板彈起最高腳底 y≈280, 鉤爪從平台一彈最高腳底 y≈178, 都過不了門

## 操作(只用鍵盤)

| 鉤爪: 進入瞄準(幽靈發光時) / 瞄準中彈出 | Z |

瞄準中畫面要顯示提示「Z 彈出 / X 取消」。

## 勝負與結束
- 勝利: 任一代角色碰到終點旗 → 顯示過關字樣並播放三代同時回放, 按空白鍵回到第 1 代開局
- 失敗: 第 3 代死亡 → 顯示失敗畫面, 按空白鍵回到第 1 代開局
- 開啟網頁先顯示說明頁, 翻完進入遊戲

## 範圍邊界
- 只有一關, 無難度曲線、無計分
- 無怪物; 無「這一代重來」、無重錄上一代, 只有整關重來
- 鉤爪只能鉤幽靈, 不能鉤平台、牆、升降台或翹翹板
- 只有一個升降台、一組門、一座翹翹板
- 升降台不會夾死角色(從下方穿過)
- 無音效、無存檔、無慢動作(瞄準暫停除外)
