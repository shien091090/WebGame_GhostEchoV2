# 接力鑰匙(一把鑰匙, 從前一代手上接過)

## 概述
走到終點前必須先死, 死掉的自己變成不斷重演的幽靈, 下一個自己踩它、搭它、鉤它, 讓它守住開關, 三個人內摸到旗子。這款的新機制是**接力鑰匙**: 終點前有一道鎖, 全關只有一把鑰匙。誰撿走鑰匙, 鑰匙就跟著那一代; 那一代死了, 鑰匙只留在它的幽靈手上, 下一代要碰到「拿著鑰匙的幽靈」才能把鑰匙接過來。鑰匙像接力棒一樣一代傳一代, 最後一棒帶到終點開鎖。
本款同時套用使用者提案的兩項改動: 前一代路線只畫接下來 5 秒、鉤爪改為瞄準式(時間暫停 → 看方向與力道 → 彈出或取消)。
驗證假設: H27 H28 H29 H31 H32(並沿用 H03 H05 H07 H11 H12 H13 H14 H18 H23)

## 核心循環
第 1 代撿起鑰匙, 站上升降台開關守著, 替第 2 代開電梯, 然後死去 → 第 2 代碰一下第 1 代幽靈接過鑰匙, 搭電梯上平台一, 在平台一跳一次給第 3 代鉤、再去踩住門開關 → 第 3 代看不到第 1 代, 跳上第 2 代幽靈的頭順手接過鑰匙, 被它載上平台一, 瞄準鉤它的跳躍飛上平台二, 趁門開、用鑰匙開鎖, 摸到旗子 → 過關看三代合力回放(鑰匙一路在三代手上傳遞)。

## 規則
1. 單一畫面、單一關卡, 不捲動。座標以畫布左上為原點, y 向下
2. 角色左右走、跳躍; 受重力, 落地才能起跳(地面、平台、升降台、幽靈頭頂都算落地)
3. 地面為實心; 空中平台與升降台為單向平台: 從下方可穿過, 從上方落下時會站上去
4. 角色掉出畫面下緣即死亡; 碰到尖刺即死亡
5. 共三代角色, 第 1 代開局出生在出生點
6. 每代從出生到死亡的每一幀都被記錄(60 幀/秒): 位置、朝向、動作狀態、是否著地、是否帶著鑰匙、鉤索兩端(只在彈出後的鉤索顯示時間內才有)。瞄準暫停期間時間不前進、不記錄。錄製達 60 秒時該代自動死亡
7. 某代死亡後播放 0.6 秒死亡演出, 接著下一代在出生點出生; 升降台、門、鎖回到初始狀態後再依當下狀況運作(鑰匙不回原位, 見規則 27)
8. 新一代出生的同一幀, 上一代的紀錄從第 0 幀開始以「幽靈」重播; 播完最後一幀後立刻從第 0 幀重新開始, 無限循環
9. 場上只存在「上一代」的幽靈: 操控第 2 代時只有第 1 代幽靈; 操控第 3 代時只有第 2 代幽靈, 第 1 代幽靈完全消失(不顯示、不可踩、不可鉤、不壓開關、不能交鑰匙)
10. 幽靈不受尖刺、坑洞、門、鎖、升降台影響, 純粹照紀錄重播; 紀錄中帶鉤索的幀, 幽靈連同它的鉤索一起顯示; 紀錄中帶著鑰匙的幀, 幽靈手上顯示鑰匙
11. 幽靈只有頭頂可以站: 角色下落時(垂直速度 ≥ 0)腳底穿過幽靈頭頂、且水平有重疊, 就站在幽靈頭上。幽靈的其他部位不擋角色
12. 站在幽靈頭上時, 角色跟著幽靈移動(水平位移相加, 腳底每幀貼齊幽靈頭頂, 幽靈上升或下降都跟著); 可以從幽靈頭上起跳; 水平走出幽靈頭頂範圍即離開
13. 幽靈循環從最後一幀跳回第 0 幀時, 站在它頭上的角色不跟著瞬移, 改為進入空中狀態

### 前一代路線(5 秒)
14. 畫面畫出當前幽靈「從目前這一幀起、接下來 300 幀(5 秒)」的紀錄位置(每幀幽靈中心連成線), 單一顏色。紀錄剩不到 300 幀時接回第 0 幀繼續畫, 但總長最多一整圈; 接回處斷開成兩段, 不連線。不畫已經走過的部分、不分色、不加預影

### 鉤爪(瞄準式)
15. 每代有 2 次鉤爪; 下一代出生時重新給 2 次
16. 可鉤條件: 幽靈存在、角色中心與幽靈中心距離 ≤ 鉤爪範圍、本代還有次數。條件成立時幽靈顯示「可鉤」發光
17. 按 Z 且可鉤 → 進入「瞄準」: 時間暫停(角色、幽靈、升降台、門、關門延遲、錄製全部停住)。按 Z 但不可鉤: 不發生任何事
18. 瞄準中畫出: 從角色中心到幽靈中心的虛線(彈出方向); 從角色中心沿同方向的箭頭, 長度 = 當下彈出速度 × 0.3 秒。蓄力值從 0 開始依真實時間增加, 1 秒到滿後停在滿。彈出速度 = 速度上限 × (0.3 + 0.7 × 蓄力值); 速度上限看幽靈當下狀態: 在空中(紀錄中未著地)用「騰空上限」, 著地用「著地上限」
19. 瞄準中再按 Z → 彈出: 扣 1 次, 時間恢復; 角色速度直接設為「方向 × 彈出速度」並離開地面或幽靈頭頂。彈出後的「彈射時間」內左右鍵無效、保留水平速度, 之後恢復一般操控; 全程受重力。撞到實心牆、關著的門或鎖時水平速度歸零。彈出後在「鉤索顯示時間」內畫鉤索: 角色中心 → 被鉤幽靈當下中心
20. 瞄準中按 X → 取消: 不扣次數, 時間恢復, 角色維持暫停前的狀態
21. 瞄準中只有 Z、X、R 有作用; 其他按鍵無效

### 開關、升降台、門
22. 開關有兩個: 升降台開關(在地面)、門開關(在平台一)。開關被壓住的條件: 角色或場上的幽靈處於著地狀態, 腳底與開關所在平台表面同高, 且水平與開關有重疊
23. 升降台開關被壓住期間, 升降台以「升降速度」往上移, 到最高點停住; 放開後以同速往下移, 回到最低點停住。站在升降台上的角色跟著上下移動。升降台最低點時頂面與地面齊平, 下方地面一直存在
24. 門在門開關被壓住期間開啟; 開關放開後經過「關門延遲」才關上。門關著時是實心牆, 角色無法穿過也跳不過
25. 門要關上的那一刻若角色與門重疊, 門延後到角色離開後才關
26. 每個開關與它控制的物件要用同一種顏色標示

### 接力鑰匙(新)
27. 全關只有一把鑰匙, 開局放在「鑰匙位置」。鑰匙還在原位時, 角色碰到它(碰撞框重疊)就撿起; 撿起後原位變空, **之後每一代出生都不會再出現**, 直到整關重來
28. 角色帶著鑰匙時, 鑰匙一直跟著它直到它死亡; 不能丟下、不能給出。帶著鑰匙的角色死亡後, 場上就沒有實體鑰匙了, 只剩它的幽靈在重播中「拿著鑰匙」
29. 接過鑰匙: 角色沒有鑰匙、且碰到「此刻紀錄中拿著鑰匙」的幽靈(碰撞框重疊, 或站在它頭上)時, 角色得到鑰匙。幽靈的重播不受影響, 照紀錄繼續拿著
30. 鎖: 立在平台二上的實心牆, 角色帶著鑰匙碰到鎖時鎖打開, 這一代剩下的時間都開著; 鑰匙不會用掉。沒帶鑰匙時鎖和關著的門一樣擋路、跳不過
31. 鎖與鑰匙用同一種顏色(與兩個開關的顏色都不同)
32. HUD 顯示本代是否帶著鑰匙; 鑰匙已被撿走、本代沒拿到、上一代的幽靈也從沒拿過鑰匙時, 這一代不可能過關(只能整關重來), 遊戲不另外提示

### 結束
33. 「整關重來」: 回到第 1 代開局, 清空所有紀錄, 鑰匙回到原位。沒有其他任何重來方式
34. 角色碰到終點旗即過關
35. 過關後進入回放: 第 1、2 代的紀錄與過關那一代從出生到過關的紀錄, 同時從第 0 幀開始以幽靈播放並循環; 三代都顯示(含鉤索、手上的鑰匙), 兩個開關、升降台、門照回放中的狀態運作; 鎖在回放中畫成開著; 鑰匙原位畫成空的; 回放時不畫路線
36. 第 3 代死亡即失敗

設計意圖(給 RD 驗算用, 不給玩家看):
- 一般跳 168 px; 踩頭 +56; 搭著跳躍中的幽靈再在最高點跳, 最多 392 px。兩段高差都是 420 px, 不靠機關上不去

- 第 1 代沒有幽靈可用, 只能在地上; 主解是撿鑰匙後守升降台開關約 4 秒以上(第 2 代在開關上碰它接鑰匙 → 走到電梯約 1 秒 → 升降 2.1 秒), 之後走進右邊坑結束
- 另解: 第 1 代撿鑰匙後在地上跳, 第 2 代接鑰匙後鉤它上平台一(用掉 1 次)
- 第 2 代上不了平台二(第 1 代幽靈永遠在地上, 從平台一鉤它方向朝下)。它要在平台一 x 240~440 跳一次給第 3 代鉤, 然後踩住門開關不放(之後可走進左邊尖刺結束)
- 第 3 代看不到第 1 代, 升降台不會升; 上平台一要先跳上第 2 代幽靈的頭(在地上時頭頂離地 56 px), 站上頭的那一刻就接到鑰匙, 再被它載上去; 也可以在地上任何時候碰它接鑰匙
- 若第 2 代忘了接鑰匙, 第 3 代就拿不到鑰匙、必定過不了關——這是 H32 要觀察的負面體驗
- 第 3 代在平台一鉤第 2 代的跳躍上平台二, 趁門開穿過門、碰鎖開鎖、摸旗; 門與鎖相隔 36 px, 門開著的時間要夠第 3 代走過門再碰鎖(鎖一碰就開, 不需停留)
- 門頂與鎖頂都是 y=140; 從平台二跳最高腳底 y≈192, 鉤爪從平台一彈最高腳底 y≈178, 都過不了

## 勝負與結束
- 勝利: 任一代角色碰到終點旗 → 顯示過關字樣並播放三代同時回放, 按空白鍵回到第 1 代開局
- 失敗: 第 3 代死亡 → 顯示失敗畫面, 按空白鍵回到第 1 代開局
- 開啟網頁先顯示說明頁, 翻完進入遊戲

## 範圍邊界
- 只有一關, 無難度曲線、無計分
- 無怪物; 無「這一代重來」、無重錄上一代, 只有整關重來
- 鉤爪只能鉤幽靈, 不能鉤平台、牆、升降台、門或鎖
- 只有一把鑰匙、一道鎖、一個升降台、一組門
- 鑰匙不能丟、不能放下; 幽靈不能開鎖
- 升降台不會夾死角色(從下方穿過)
- 無音效、無存檔、無慢動作(瞄準暫停除外)
