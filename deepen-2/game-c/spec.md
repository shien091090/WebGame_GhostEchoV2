# 起跑哨(一聲令下, 前一代立刻從頭出發)

## 概述
走到終點前必須先死, 死掉的自己變成不斷重演的幽靈, 下一個自己踩它、搭它、鉤它, 讓它守住開關, 三個人內摸到旗子。這款的新機制是**起跑哨**: 按 C 吹哨, 前一代的幽靈立刻回到出生點、從頭重演。玩家先站好位置、看準路線, 再一聲令下讓前一代「現在開始跑」, 不用乾等它繞完一輪, 像和隊友喊「一二三, 走!」一起出發。
關卡與 deepen-1 的「升降接力」相同(使用者評為最有接力感), 方便對照新機制的效果。
本款同時套用使用者提案的兩項改動: 前一代路線只畫接下來 5 秒、鉤爪改為瞄準式(時間暫停 → 看方向與力道 → 彈出或取消)。
驗證假設: H27 H28 H29 H33 H34(並沿用 H03 H04 H05 H07 H11 H12 H13 H14 H18 H23)

## 核心循環
第 1 代站上升降台開關守著, 替第 2 代開電梯, 然後死去 → 第 2 代走到電梯上站好, 吹哨讓第 1 代幽靈立刻出發去踩開關, 搭電梯上平台一, 在平台一跳一次給第 3 代鉤、再去踩住門開關 → 第 3 代看不到第 1 代, 站好後吹哨, 跳上第 2 代幽靈的頭被它載上平台一, 瞄準鉤它的跳躍飛上平台二, 趁門開衝向旗子 → 過關看三代合力回放。

## 規則
1. 單一畫面、單一關卡, 不捲動。座標以畫布左上為原點, y 向下
2. 角色左右走、跳躍; 受重力, 落地才能起跳(地面、平台、升降台、幽靈頭頂都算落地)
3. 地面為實心; 空中平台與升降台為單向平台: 從下方可穿過, 從上方落下時會站上去
4. 角色掉出畫面下緣即死亡; 碰到尖刺即死亡
5. 共三代角色, 第 1 代開局出生在出生點
6. 每代從出生到死亡的每一幀都被記錄(60 幀/秒): 位置、朝向、動作狀態、是否著地、鉤索兩端(只在彈出後的鉤索顯示時間內才有)、「這一幀上一代幽靈播到第幾幀」(第 1 代沒有, 記空)。瞄準暫停期間時間不前進、不記錄。錄製達 60 秒時該代自動死亡
7. 某代死亡後播放 0.6 秒死亡演出, 接著下一代在出生點出生; 升降台與門回到初始狀態後再依當下開關狀態運作
8. 新一代出生的同一幀, 上一代的紀錄從第 0 幀開始以「幽靈」重播; 播完最後一幀後立刻從第 0 幀重新開始, 無限循環
9. 場上只存在「上一代」的幽靈: 操控第 2 代時只有第 1 代幽靈; 操控第 3 代時只有第 2 代幽靈, 第 1 代幽靈完全消失(不顯示、不可踩、不可鉤、不壓開關)
10. 幽靈不受尖刺、坑洞、門、升降台影響, 純粹照紀錄重播; 紀錄中帶鉤索的幀, 幽靈連同它的鉤索一起顯示
11. 幽靈只有頭頂可以站: 角色下落時(垂直速度 ≥ 0)腳底穿過幽靈頭頂、且水平有重疊, 就站在幽靈頭上。幽靈的其他部位不擋角色
12. 站在幽靈頭上時, 角色跟著幽靈移動(水平位移相加, 腳底每幀貼齊幽靈頭頂, 幽靈上升或下降都跟著); 可以從幽靈頭上起跳; 水平走出幽靈頭頂範圍即離開
13. 幽靈循環從最後一幀跳回第 0 幀時, 站在它頭上的角色不跟著瞬移, 改為進入空中狀態

### 前一代路線(5 秒)
14. 畫面畫出當前幽靈「從目前這一幀起、接下來 300 幀(5 秒)」的紀錄位置(每幀幽靈中心連成線), 單一顏色。紀錄剩不到 300 幀時接回第 0 幀繼續畫, 但總長最多一整圈; 接回處斷開成兩段, 不連線。不畫已經走過的部分、不分色、不加預影

### 起跑哨(新)
15. 按 C 吹哨: 場上的幽靈立刻跳到紀錄第 0 幀(出生點)從頭重播。路線跟著從第 0 幀重畫
16. 吹哨的那一幀, 站在幽靈頭上的角色不跟著瞬移, 改為進入空中狀態(同規則 13); 幽靈原本壓住的開關若因此放開, 照一般規則處理(升降台下降、門經關門延遲後關)
17. 吹哨不限次數、沒有冷卻; 場上沒有幽靈時(第 1 代)按 C 不發生任何事; 瞄準中按 C 無效
18. 吹哨時在幽靈的新位置(出生點)播放一圈擴散的「哨音波紋」0.4 秒, 讓玩家看出幽靈是被叫回來的
19. 吹哨只改變幽靈「播到哪一幀」, 不改動任何紀錄; 這一代自己的錄製照常進行(吹哨不算重來)

### 鉤爪(瞄準式)
20. 每代有 2 次鉤爪; 下一代出生時重新給 2 次
21. 可鉤條件: 幽靈存在、角色中心與幽靈中心距離 ≤ 鉤爪範圍、本代還有次數。條件成立時幽靈顯示「可鉤」發光
22. 按 Z 且可鉤 → 進入「瞄準」: 時間暫停(角色、幽靈、升降台、門、關門延遲、錄製全部停住)。按 Z 但不可鉤: 不發生任何事
23. 瞄準中畫出: 從角色中心到幽靈中心的虛線(彈出方向); 從角色中心沿同方向的箭頭, 長度 = 當下彈出速度 × 0.3 秒。蓄力值從 0 開始依真實時間增加, 1 秒到滿後停在滿。彈出速度 = 速度上限 × (0.3 + 0.7 × 蓄力值); 速度上限看幽靈當下狀態: 在空中(紀錄中未著地)用「騰空上限」, 著地用「著地上限」
24. 瞄準中再按 Z → 彈出: 扣 1 次, 時間恢復; 角色速度直接設為「方向 × 彈出速度」並離開地面或幽靈頭頂。彈出後的「彈射時間」內左右鍵無效、保留水平速度, 之後恢復一般操控; 全程受重力。撞到實心牆或關著的門時水平速度歸零。彈出後在「鉤索顯示時間」內畫鉤索: 角色中心 → 被鉤幽靈當下中心
25. 瞄準中按 X → 取消: 不扣次數, 時間恢復, 角色維持暫停前的狀態
26. 瞄準中只有 Z、X、R 有作用; 其他按鍵無效

### 開關、升降台、門
27. 開關有兩個: 升降台開關(在地面)、門開關(在平台一)。開關被壓住的條件: 角色或場上的幽靈處於著地狀態, 腳底與開關所在平台表面同高, 且水平與開關有重疊
28. 升降台開關被壓住期間, 升降台以「升降速度」往上移, 到最高點停住; 放開後以同速往下移, 回到最低點停住。站在升降台上的角色跟著上下移動。升降台最低點時頂面與地面齊平, 下方地面一直存在
29. 門在門開關被壓住期間開啟; 開關放開後經過「關門延遲」才關上。門關著時是實心牆, 角色無法穿過也跳不過
30. 門要關上的那一刻若角色與門重疊, 門延後到角色離開後才關
31. 每個開關與它控制的物件要用同一種顏色標示

### 結束
32. 「整關重來」: 回到第 1 代開局, 清空所有紀錄。沒有其他任何重來方式
33. 角色碰到終點旗即過關
34. 過關後進入回放, 要重現每一代當時「看到的幽靈在哪一幀」(含吹哨造成的跳轉): 以過關那一代的紀錄為主軸, 從第 0 幀播到過關那一幀後循環; 主軸第 f 幀時, 上一代以「主軸第 f 幀記下的上一代播放幀」顯示, 再上一代以「上一代那一幀記下的播放幀」顯示, 一路往前推。三代都顯示(含鉤索), 兩個開關、升降台、門照回放中的壓住狀態運作; 回放時不畫路線, 不畫哨音波紋; 回放中按 C 無效。若過關的是第 2 代, 只回放第 1、2 代
35. 第 3 代死亡即失敗

設計意圖(給 RD 驗算用, 不給玩家看):
- 關卡與 deepen-1 game-c 完全相同, 只換掉鉤爪規則、路線長度, 並加上起跑哨; 讓使用者能直接比較「有沒有哨子」的差別
- 一般跳 168 px; 踩頭 +56; 搭著跳躍中的幽靈再在最高點跳, 最多 392 px。兩段高差都是 420 px, 只能靠升降台或鉤騰空幽靈
- 鉤爪(騰空上限 1700)正上方彈出最高約 602 px, 要越過 420 px 需垂直分速 ≥ 1420, 即方向偏離正上方 ≤ 約 33° 且蓄力約 76% 以上; 鉤著地幽靈最高約 133 px, 沒用
- 第 1 代一個人無法同時壓開關又搭電梯, 必死。主解: 第 1 代守升降台開關約 4 秒以上, 之後走進右邊坑結束
- 哨子的用途: 第 2 代可以先走到升降台上站好, 再吹哨讓第 1 代幽靈從頭跑去踩開關(第 1 代走到開關約 0.5 秒), 不必在第 1 代下一輪之前來回趕路; 第 3 代可以先站到第 2 代幽靈經過的位置, 再吹哨讓它「現在出發」
- 另解: 第 1 代在地上跳, 第 2 代鉤它上平台一
- 第 2 代上不了平台二(第 1 代幽靈永遠在地上)。它要在平台一 x 240~440 跳一次給第 3 代鉤, 然後踩住門開關不放(之後可走進左邊尖刺結束)
- 第 3 代看不到第 1 代, 升降台不會升; 上平台一要先跳上第 2 代幽靈的頭, 被它載上去; 在平台一等第 2 代幽靈跳起時瞄準鉤它上平台二
- 吹哨的取捨: 第 3 代在平台一等鉤時若吹哨, 第 2 代幽靈會被叫回地面出生點、門開關也跟著放開——吹錯時機會讓門關上, 要等它再走一輪(或再吹一次也沒用, 它還是從頭走)。這是 H34「哨子讓人搞混」要觀察的地方
- 過關回放不能像其他款一樣讓三份紀錄同時從第 0 幀播: 吹哨改過幽靈的播放位置, 那樣播電梯與門的時機會對不上、看起來沒成功。所以每幀多記「上一代播到第幾幀」, 回放沿著這條鏈還原(規則 34), 畫面會與實際遊玩時一致
- 門頂 y=140; 從平台二跳最高腳底 y≈192, 鉤爪從平台一彈最高腳底 y≈178, 都過不了門

## 勝負與結束
- 勝利: 任一代角色碰到終點旗 → 顯示過關字樣並播放三代同時回放, 按空白鍵回到第 1 代開局
- 失敗: 第 3 代死亡 → 顯示失敗畫面, 按空白鍵回到第 1 代開局
- 開啟網頁先顯示說明頁, 翻完進入遊戲

## 範圍邊界
- 只有一關, 無難度曲線、無計分
- 無怪物; 無「這一代重來」、無重錄上一代, 只有整關重來; 吹哨只改幽靈播放位置, 不是重錄
- 吹哨只能讓幽靈回到第 0 幀, 不能暫停、倒轉或跳到其他幀
- 鉤爪只能鉤幽靈, 不能鉤平台、牆或升降台
- 只有一個升降台、一組門
- 升降台不會夾死角色(從下方穿過)
- 無音效、無存檔、無慢動作(瞄準暫停除外)
