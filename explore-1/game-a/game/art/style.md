# 疊影 美術規格

> index.html 必須宣告 `<meta charset="utf-8">`, 否則 art.js 的中文字串會亂碼。
> 以 `<script src="art/art.js">` 載入(非 module), 全域物件 `window.Art`。

## 邏輯畫布尺寸

720 × 1280(`Art.canvas`)。HUD 佔 y 0~100, 遊戲區 y 100~1280。

## 形狀語言

圓角方塊身體、扁平無漸層; 「實心 = 實體 / 可依靠, 虛線 = 可穿過 / 不完全存在」。

## 理念落實

- P0 辨識度先於好看: 玩家 = 暖橘實心, 幽靈 = 冷青半透明虛線框, 危險 = 唯一的紅, 終點 = 唯一的金黃; 四類物件色相各自分開。
- P1 視覺權重跟著決策迫切度: 最亮的是玩家、幽靈頭頂亮邊、播放位置標記; 背景格線 3.5% 不透明、路線 45% 虛線, 都退到後面。
- P2 規則上存在的東西畫面上就要存在: 「幽靈只有頭頂能站」畫成幽靈身上唯一實心不透明的亮邊; 「單向平台從下可穿」畫成下緣虛線 + 上指箭頭紋; 路線起點方塊、終點叉標出循環從哪跳回; R / Backspace 常駐在 HUD。
- P3 一本字典: 實心亮邊 = 可站(地面、平台、幽靈頭頂共用); 青色 = 上一代(幽靈、路線、HUD 幽靈圖示、說明頁共用); HUD 與說明頁的代數小人直接用遊戲內畫法。
- P4 兩條通道: 玩家 vs 幽靈 = 色相(橘 / 青)+ 填法(實心 / 半透明虛線框); 地面 vs 單向平台 = 厚度 + 下緣實 / 虛 + 紋理(磚紋 / 上指箭頭)。
- P7 每個元素掙得版面: 不畫出生點標記、不在角色旁掛狀態字; 代數只用胸口小數字 + HUD 一列小人。
- P9 最混亂時驗收: 玩家站在幽靈頭上時兩者重疊, 靠色相 + 實心 / 虛線仍分得開; 幽靈頭頂亮邊畫在幽靈最上層, 玩家腳底貼上時看得到接觸線。
- P13 事件排隊: 本作只有死亡、過關、失敗三種事件, 死亡只換玩家外觀(灰 + 叉眼), 結束畫面只在 win / lose 出現一張卡, 不疊。
- P15 回饋強度與份量成正比: 死一代 = 只換角色外觀(小); 過關 / 失敗 = 全畫面暗幕 + 大字卡(大)。
- P17 進度圖形與數字分工: HUD 小人列給「誰是幽靈、誰已消失、還剩幾人」(數字給不了的關係), 文字「第 N / 3 人」給精確讀數。
- P18 重要資訊不只一瞬間: 已用掉的代數常駐在 HUD 小人列(灰虛線 = 消失、青 = 幽靈)。
- P19 資訊貼著物件: 代數寫在角色胸口; 幽靈播放進度直接標在路線上(而不是另做進度條)。
- P21 示意圖選分岔例: 說明第 3 頁並排「踩頭再跳 → 上得去 ✓」與「直接跳 → 腳底差 32px 碰不到 ✗」, 兩格同平台同高度。

## 物件表

所有座標為物件左上角(drawGhostPath 除外)。每個函式自己 save / restore。

| 物件 | 函式 | state 欄位 | 各狀態視覺差異 |
|---|---|---|---|
| 背景 | `drawBackground(ctx)` | 無 | 深藍漸層 + 每 40px 極淡格線(幫目測高度) |
| 平台 | `drawPlatform(ctx, {x, y, w, h})` | x, y, w, h | **h ≥ 48 畫成實心地面**(磚紋、亮上緣); **h < 48 畫成單向平台**(半透明本體、亮上緣、下緣虛線、上指箭頭紋)。RD 照關卡表傳即可(地面 h=80, 平台 h=24) |
| 尖刺 | `drawSpike(ctx, {x, y, w})` | x, y, w | 紅色三角一排, 每顆約 16px 寬; 高固定 24 |
| 終點旗 | `drawGoal(ctx, {x, y})` | x, y | 白旗桿 + 金黃三角旗, 固定 48×80 |
| 幽靈路線 | `drawGhostPath(ctx, {points, progress})` | points: [{x,y}] 腳底中心, progress: 0~1 | 青色半透明虛線連點; points[0] 畫小方塊(起點), 最後一點畫小叉(死亡處); progress 位置畫深底白框環。points 為空時不畫 |
| 幽靈 | `drawGhost(ctx, {x, y, facing, state, gen})` | facing: 1/-1; state: idle/run/air; gen: 1~3 | 青色 38% 填色 + 虛線框, 頭頂 5px 實心亮邊(唯一可站處); 眼睛偏向 facing 側; idle 腿直立、run 腿前後叉開、air 腿縮起眼睛上移; 胸口寫 gen |
| 玩家 | `drawPlayer(ctx, {x, y, facing, state, gen})` | facing: 1/-1; state: idle/run/air/dead; gen: 1~3 | 暖橘實心 + 深橘框; 姿勢同幽靈; **dead = 灰色身體 + 叉眼**(死亡演出 0.6 秒期間傳 dead); 胸口寫 gen |
| HUD | `drawHud(ctx, {gen, maxGen, phase})` | gen: 當前代; maxGen: 3; phase: play/dying/win/lose | 頂部 0~100 底板; 左側 maxGen 個小人: 當前代 = 橘(dying / lose 時灰叉眼)、上一代 = 青幽靈、更早 = 灰虛線淡出、未輪到 = 空心框; 「第 N / 3 人」; 右側 R / Backspace 鍵帽 + 說明。**win / lose 時另畫全畫面暗幕 + 結束卡**(「過關!」金 / 「失敗」紅 + 「按空白鍵重來」) |
| 說明頁 | `drawGuidePage(ctx, {page})` | page: 0~4 | 自帶背景, 整頁覆蓋; 標題、文字、示意圖、底部「空白鍵 下一頁 / 開始遊戲」與頁碼點。共 5 頁 |

### 繪製層級(由下到上)

drawBackground → drawPlatform(全部)→ drawSpike → drawGoal → drawGhostPath → drawGhost → drawPlayer → drawHud。
玩家必須畫在幽靈之上(站在頭上時腳底壓著亮邊)。說明頁顯示時只呼叫 drawGuidePage。
