# 疊影(規劃路線、替自己鋪路的解謎感)

## 概述
走到終點前必須先死, 死掉的自己會變成不斷重演的幽靈, 下一個自己踩著它往上爬; 三個人內摸到旗子過關。畫面會畫出前一代幽靈的完整路線, 並可只重來當前這一代, 讓玩家專心「規劃」而不是反覆試錯。
驗證假設: H01 H02 H03 H04 H06 H07 H08 H09

## 核心循環
控制角色移動 → 有意識地決定「這一代要停在哪、待多久、死在哪」→ 死亡後這段動作變成幽靈 → 下一代踩著幽靈到原本上不去的高處 → 想看看自己的安排能不能一路鋪到終點, 不行就重排這一代再試。

## 規則
1. 單一畫面、單一關卡, 不捲動。座標以畫布左上為原點, y 向下
2. 角色左右走、跳躍; 受重力, 落地才能起跳
3. 地面為實心; 空中平台為單向平台: 從下方可穿過, 從上方落下時會站上去
4. 角色掉出畫面下緣即死亡; 碰到尖刺即死亡
5. 共三代角色, 第 1 代開局出生在出生點
6. 每代從出生到死亡的每一幀位置、朝向、是否著地都被記錄(60 幀/秒)。錄製達 60 秒時該代自動死亡
7. 某代死亡後播放 0.6 秒死亡演出, 接著下一代在出生點出生
8. 新一代出生的同一幀, 上一代的紀錄從第 0 幀開始以「幽靈」重播; 播完最後一幀後立刻從第 0 幀重新開始, 無限循環
9. 場上只存在「上一代」的幽靈: 操控第 2 代時只有第 1 代幽靈; 操控第 3 代時只有第 2 代幽靈, 第 1 代幽靈完全消失(不顯示、不可踩)
10. 幽靈只有頭頂可以站: 角色下落時(垂直速度 ≥ 0)腳底穿過幽靈頭頂、且水平有重疊, 就站在幽靈頭上。幽靈的其他部位不擋角色
11. 站在幽靈頭上時, 角色跟著幽靈移動(幽靈水平位移多少, 角色就加多少; 角色腳底貼齊幽靈頭頂); 可以從幽靈頭上起跳
12. 幽靈循環從最後一幀跳回第 0 幀時, 站在它頭上的角色不跟著瞬移, 改為進入空中狀態
13. 幽靈不會受尖刺、坑洞影響, 純粹照紀錄重播
14. 畫面顯示當前幽靈的整條紀錄路線, 並標出幽靈目前播到路線上的哪一點
15. 「這一代重來」: 當前角色回到出生點、本代紀錄清空重錄, 幽靈從第 0 幀重新播放; 不消耗代數
16. 「整關重來」: 回到第 1 代開局, 清空所有紀錄
17. 角色碰到終點旗即過關
18. 第 3 代死亡即失敗

### 關卡配置
| 物件 | x | y | 寬 | 高 | 說明 |
|---|---|---|---|---|---|
| 地面 | 0 | 1200 | 600 | 80 | 實心; x 600~720 是坑, 掉下去出畫面即死 |
| 平台一 | 0 | 1000 | 480 | 24 | 單向平台 |
| 尖刺 | 0 | 976 | 80 | 24 | 平台一左端上方 |
| 平台二 | 300 | 800 | 420 | 24 | 單向平台 |
| 終點旗 | 640 | 720 | 48 | 80 | 立在平台二右側 |
| 出生點 | 60 | 1144 | — | — | 角色左上角位置 |

設計意圖(給 RD 驗算用, 不給玩家看):
- 一般跳躍最高 168 px, 平台間高差 200 px: 不靠幽靈上不去任何平台, 第 1 代必死
- 踩幽靈頭(+56 px)再跳可達 224 px: 第 2 代踩在地面待命的第 1 代幽靈上到平台一; 第 2 代在平台二下方待命後死去
- 第 3 代看不到第 1 代, 只能先跳上第 2 代幽靈的頭(在地面時離地 56 px, 一般跳得上), 被它載上平台一, 再從它在平台一待命時的頭上跳上平台二

## 操作(只用鍵盤)
| 玩家動作 | 按鍵 |
|---|---|
| 左右移動 | ← / → |
| 跳躍 | 空白鍵 或 ↑ |
| 這一代重來 | R |
| 整關重來 | Backspace |
| 說明翻下一頁 / 最後一頁開始遊戲 | 空白鍵 |
| 過關或失敗畫面重新開始 | 空白鍵 |

## 勝負與結束
- 勝利: 任一代角色碰到終點旗 → 顯示過關畫面, 按空白鍵回到第 1 代開局
- 失敗: 第 3 代死亡 → 顯示失敗畫面, 按空白鍵回到第 1 代開局
- 開啟網頁先顯示說明頁, 翻完進入遊戲

## 範圍邊界
- 只有一關, 無難度曲線、無計分、無計時排行
- 無怪物、無鉤爪、無開關機關
- 無音效、無存檔
- 不做角色加速度、二段跳、蹬牆等額外移動技
