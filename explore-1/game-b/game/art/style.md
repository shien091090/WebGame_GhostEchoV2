# 鉤影 美術規格

index.html 必須宣告 `<meta charset="utf-8">`(art.js 內有中文字串)。以 `<script src="art/art.js">` 一般 script 載入, 全域 `window.Art`。

## 邏輯畫布尺寸

720 × 1280(`Art.canvas`)。HUD 佔 y 0~100, 遊戲區 y 100~1280。

色相: 橘 30° / 綠 142° / 青 195° / 紫 276° / 紅 354°。紫(鉤爪)與青(幽靈)同框長在幽靈身上, 差 81°。玩家橘與尖刺紅色相相鄰, 但兩者類別不同(角色 vs 場景三角齒), 靠外形分。

## 形狀語言

扁平、無外光; 角色是圓頂豆形、場景是直角方塊; 實線 = 實體, 虛線 = 可穿過 / 不在場。

## 理念落實

- P0 辨識度先於好看: 五種物件各有獨立外形(豆形角色 / 平頂虛線幽靈 / 方塊平台 / 三角齒 / 旗), 不靠顏色單獨區分
- P1 視覺權重跟著決策迫切度: 全畫面最高對比的是「幽靈可鉤」的紫角框與空中時的紫光; 背景點陣與危險漸層壓到最低
- P2 規則上存在的東西畫面上就存在: 幽靈「只有頭頂能站」畫成頭頂一條不透明亮線、身體虛線半透明; 單向平台下半格柵 + 虛線底 = 可從下穿過; 強甩 / 弱甩(幽靈在空中與否)在可鉤標示上分成粗角框 + 雙箭頭 vs 細角框 + 單箭頭; 鉤爪本次已用過顯示在 HUD
- P3 一個意義一種長相: 紫色只代表鉤爪; HUD 代數小人與說明第 5 頁用同一套(實心橘 = 現在、半透明青 = 幽靈、極淡 = 消失、虛線空框 = 等待)
- P4 關鍵區分走兩條通道: 角色 vs 幽靈 = 顏色 + 不透明度 + 頂部形狀(圓頂 vs 平頂); 強甩 vs 弱甩 = 角框粗細 + 箭頭數 + 內部紫光
- P7 每個元素掙得版面: 角色身上不重寫代數(HUD 已有); 說明頁圖說只留圖畫不出的因果
- P9 以最混亂的一刻驗收: 拉動中(角色紫框 + 鉤索 + 幽靈紫角框)三者同色但形狀分開: 線 / 角色外框 / 幽靈四角
- P13 事件排隊: 死亡演出期間只有一條橫幅, 結束畫面整片蓋上、不與橫幅同時出現(phase 互斥)
- P15 回饋強度和份量成正比: 死亡 = 小橫幅; 過關 / 失敗 = 全畫面面板
- P17 進度類: 本作無進度條, 代數用可數小人, 數字「2 / 3」給讀數、小人給「誰是幽靈、誰已消失」
- P18 重要資訊不只一瞬間: 鉤爪已用 / 可用常駐於 HUD, 不只在按下那刻顯示
- P19 資訊貼著物件: 「可鉤」直接長在幽靈本體四角, 不另掛標籤
- P21 示意圖選分岔的例子: 第 4 頁並排「幽靈站著 → 甩不上(✗)」與「幽靈在空中 → 甩上平台(✓)」, 兩格只差幽靈是否離地

## 物件表

所有座標為物件左上角(drawHook 除外)。每個函式自行 save/restore。

| 物件 | 函式 | state 欄位 | 各狀態視覺 |
|---|---|---|---|
| 背景 | `drawBackground(ctx)` | — | 深藍漸層 + 淡點陣; 畫面最下 40px 淡紅漸層(掉出去會死)。每幀最先畫 |
| 平台 | `drawPlatform(ctx, {x,y,w,h})` | x, y, w, h | **h ≥ 40 畫成實心地面**(磚紋, 上緣亮條); h < 40 畫成單向平台(上緣 8px 亮條可站, 下方半透明直格柵 + 虛線底 = 可從下穿過) |
| 尖刺 | `drawSpike(ctx, {x,y,w})` | x, y, w | 紅色三角齒, 齒數 = round(w/16), 高固定 24 |
| 終點旗 | `drawGoal(ctx, {x,y})` | x, y | 白旗桿 + 綠三角旗 + 底座 |
| 幽靈 | `drawGhost(ctx, {x,y,facing,state,gen,hookable})` | facing 1/-1; state idle/run/air; gen 不影響外觀; hookable 布林 | 半透明青色平頂身體 + 虛線外框, 頭頂 4px 不透明亮線(唯一可站處)。run = 雙腳前後錯開; air = 腳收起。hookable: 四角紫角框 + 白箭頭; **state=air 時**角框加粗加長、身體內紫光、雙箭頭(強甩); 著地時細角框、單箭頭(弱甩)。會乘上呼叫端的 globalAlpha |
| 鉤索 | `drawHook(ctx, {x1,y1,x2,y2})` | 起點 = 角色中心, 終點 = 幽靈頭頂中心 | 紫線(深紫襯邊)+ 終點三叉爪 |
| 玩家 | `drawPlayer(ctx, {x,y,facing,state,gen})` | facing 1/-1; state idle/run/air/hook/dead; gen 不影響外觀 | 橘色圓頂豆形 + 眼睛朝 facing。run = 身體前傾 2px、雙腳錯開; air = 腳收起; hook = 腳收起 + 紫色外框; dead = 灰色 + X 眼 |
| HUD | `drawHud(ctx, {gen,maxGen,phase,hookReady})` | gen 1~3; maxGen 3; phase play/dying/win/lose; hookReady 布林 | 左: maxGen 個代數小人(現在 = 橘、上一代 = 青幽靈、更早 = 極淡、未來 = 虛線空框)+「2 / 3」; 中: 鉤爪圖示, hookReady 紫色「Z 鉤爪 / 可用」, 否則灰色「已用過 / 落地後恢復」; 右: 按鍵提示。dying: y 116~160 中央小橫幅「倒下了 — 下一個你即將出生」(最後一代為「最後一人倒下」)。win / lose: 全畫面變暗 + 中央面板「過關! / 失敗」+「空白鍵 重來」 |
| 說明頁 | `drawGuidePage(ctx, {page})` | page 0~4 | 全畫面自繪(含底色), 不需先畫背景。頁底有頁碼點與「空白鍵 下一頁 / 開始遊戲」 |

### 繪製層級(由下到上)

drawBackground → drawPlatform(全部)→ drawSpike → drawGoal → drawGhost → drawHook → drawPlayer → drawHud。
