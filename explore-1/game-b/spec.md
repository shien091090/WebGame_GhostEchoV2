# 鉤影(抓準時機一鉤飛天的動作爽快)

## 概述
走到終點前必須先死, 死掉的自己變成不斷重演的幽靈; 下一個自己可以踩它的頭, 也可以用鉤爪鉤住它, 在它跳到空中時鉤住就能被甩上高處。平台高到只靠踩頭上不去, 一定要抓準幽靈騰空的瞬間出鉤。三個人內摸到旗子過關。
驗證假設: H01 H02 H04 H06 H07 H10 H11 H12

## 核心循環
第一代先跳一段「之後要被鉤的跳躍」再死 → 下一代等幽靈跳起、在範圍內按鉤爪 → 被甩上原本到不了的平台 → 鉤得越準飛得越爽, 失手就等幽靈下一輪再跳一次。

## 規則
1. 單一畫面、單一關卡, 不捲動。座標以畫布左上為原點, y 向下
2. 角色左右走、跳躍; 受重力, 落地才能起跳
3. 地面為實心; 空中平台為單向平台: 從下方可穿過, 從上方落下時會站上去
4. 角色掉出畫面下緣即死亡; 碰到尖刺即死亡
5. 共三代角色, 第 1 代開局出生在出生點
6. 每代從出生到死亡的每一幀位置、朝向、是否著地都被記錄(60 幀/秒)。錄製達 60 秒時該代自動死亡
7. 某代死亡後播放 0.6 秒死亡演出, 接著下一代在出生點出生
8. 新一代出生的同一幀, 上一代的紀錄從第 0 幀開始以「幽靈」重播; 播完最後一幀後立刻從第 0 幀重新開始, 無限循環
9. 場上只存在「上一代」的幽靈: 操控第 2 代時只有第 1 代幽靈; 操控第 3 代時只有第 2 代幽靈, 第 1 代幽靈完全消失(不顯示、不可踩、不可鉤)
10. 幽靈只有頭頂可以站: 角色下落時(垂直速度 ≥ 0)腳底穿過幽靈頭頂、且水平有重疊, 就站在幽靈頭上。幽靈的其他部位不擋角色
11. 站在幽靈頭上時, 角色跟著幽靈移動(水平位移相加, 腳底貼齊幽靈頭頂); 可以從幽靈頭上起跳
12. 幽靈循環從最後一幀跳回第 0 幀時, 站在它頭上的角色不跟著瞬移, 改為進入空中狀態
13. 幽靈不會受尖刺、坑洞影響, 純粹照紀錄重播
14. 鉤爪可鉤條件: 幽靈存在, 且角色中心與幽靈中心距離 ≤ 鉤爪範圍, 且本次離地後還沒鉤過。條件成立時幽靈顯示「可鉤」標示
15. 按鉤爪鍵且可鉤: 角色在拉動時間內被拉到幽靈頭頂(目標追著幽靈當下位置), 拉動期間不受重力、不能操控
16. 拉動結束瞬間: 若幽靈當下在空中(紀錄中未著地), 角色獲得向上初速「強甩速度」; 若幽靈當下著地, 獲得「弱甩速度」。水平速度歸零
17. 按鉤爪鍵但不可鉤: 不發生任何事
18. 角色落地(地面、平台、幽靈頭)後重置「本次離地已鉤過」
19. 拉動中若幽靈循環跳回第 0 幀, 鉤爪中斷, 角色以當下位置進入空中狀態
20. 「整關重來」: 回到第 1 代開局, 清空所有紀錄
21. 角色碰到終點旗即過關
22. 第 3 代死亡即失敗

### 關卡配置
| 物件 | x | y | 寬 | 高 | 說明 |
|---|---|---|---|---|---|
| 地面 | 0 | 1200 | 600 | 80 | 實心; x 600~720 是坑, 掉下去出畫面即死 |
| 平台一 | 0 | 860 | 480 | 24 | 單向平台 |
| 尖刺 | 0 | 836 | 80 | 24 | 平台一左端上方 |
| 平台二 | 260 | 540 | 460 | 24 | 單向平台 |
| 終點旗 | 640 | 460 | 48 | 80 | 立在平台二右側 |
| 出生點 | 60 | 1144 | — | — | 角色左上角位置 |

設計意圖(給 RD 驗算用, 不給玩家看):
- 平台間高差 320 px。一般跳 168 px、踩頭跳 224 px、鉤著地幽靈只甩約 88 px: 全都上不去
- 鉤空中幽靈從它頭頂再甩約 208 px: 地面那段需在幽靈離地 ≥ 76 px 時鉤(約 0.55 秒的窗口), 平台一那段需幽靈離地 ≥ 56 px
- 第 3 代看不到第 1 代, 但第 2 代幽靈的重播裡有它被鉤上去的整段飛行(屬於空中), 第 3 代可鉤它或搭它的頭上平台一

## 操作(只用鍵盤)
| 玩家動作 | 按鍵 |
|---|---|
| 左右移動 | ← / → |
| 跳躍 | 空白鍵 或 ↑ |
| 鉤爪 | Z |
| 整關重來 | R |
| 說明翻下一頁 / 最後一頁開始遊戲 | 空白鍵 |
| 過關或失敗畫面重新開始 | 空白鍵 |

## 勝負與結束
- 勝利: 任一代角色碰到終點旗 → 顯示過關畫面, 按空白鍵回到第 1 代開局
- 失敗: 第 3 代死亡 → 顯示失敗畫面, 按空白鍵回到第 1 代開局
- 開啟網頁先顯示說明頁, 翻完進入遊戲

## 範圍邊界
- 只有一關, 無難度曲線、無計分
- 無怪物、無開關機關、無路線預覽、無「這一代重來」
- 鉤爪只能鉤幽靈, 不能鉤平台或牆
- 無音效、無存檔、無慢動作
