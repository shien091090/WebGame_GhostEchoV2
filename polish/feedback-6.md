# 試玩回饋 打磨第 6 輪

日期: 2026-11-01
使用者選擇: continue(再打磨一輪)

本輪回饋來自兩部分: 使用者的直接指示, 以及對照 game-studio-lab 通用規範(_common、rd-lessons、art-lessons、audio-lessons、screen-width、interface-checklist)稽核出的不符項目。稽核項目是製作人整理, 不是使用者原話, 但使用者已同意一併修正。

## 畫面方向(使用者決定)
- 使用者問「畫面規範不是16:9嗎?」, 確認後選擇**改成 16:9 橫式**
  - 現況是直式 720×1280, PVD計畫網站電腦遊玩框是 16:9(1280×720), 直式上架電腦只佔中間一條、手機不能玩
  - 畫布改 1280×720(interface.json canvas 照 `references/screen-width.md` 的寫法); 七關地形、HUD、教學泡泡、開場橫幅、開始 / 解鎖 / 全破畫面全部依橫式重新排版
  - 關卡重排時保留每關的解法與已驗證的難度設計(例: 第 6 關練哨關的壓板升起 1.7 秒、單次升起跑不過的驗算), 換成橫式後重新驗算
  - 發布時才做的寬度依裝置(1280~1680)本輪不用做, 但排版要讓設計區 1280×720 完整、兩側之後能延伸背景

## 操作(使用者指示)
- 「吹哨C鍵改成空白」: 遊玩中吹哨改用空白鍵, C 鍵取消。空白鍵在選單畫面的「確認 / 繼續」用途不變(遊玩中空白鍵目前無作用, 不衝突)
- 「重來鍵改到esc暫停裡面」: 新增 Esc 暫停選單(暫停遊戲時間與幽靈回放), 選單內放「重來」(整關重來)與「繼續」
- 「移除R鍵，這個遊戲不會使用到R了」: R 鍵完全移除, 任何畫面按 R 都沒有作用; 程式、spec 操作表、教學、HUD、埋點裡的 R 全部清掉, 整關重來只剩 Esc 暫停選單一個入口
  - 改完動作鍵只剩 Z、X、空白鍵三個, 符合 _common「至多 3 個動作鍵」
  - 教學、HUD 鍵帽、節奏燈旁提示、條件式教學「他走太慢, R 重來」等所有提到 C / R 的地方同步改成空白鍵 / Esc
- 「第2階段教學不改」: 「到不了旗子? 先死一次」維持原樣

## 稽核出的不符項目(製作人整理, 使用者同意修)
### 會擋發布
- 背景音樂(Kevin MacLeod, CC BY 4.0)在遊戲畫面上沒有署名, 只寫在 credits.md; 開始畫面或全破畫面要放署名

### 影響體驗
- 聲音開關圖示畫在頂端資訊列裡(違反 _common: 放在資訊列下方、遊玩區右上角); 開始畫面放在右下角。橫式重排時照守則放, 並確認不擋到旗子等物件
- 解鎖頁、全破畫面沒有聲音開關圖示(按 M 有效但看不到狀態); interface 要傳靜音狀態給這兩頁
- 開場橫幅蓋住終點旗(直式時第 5、7 關整面、第 2~4 關旗頭); 橫式重排時拿各關旗子位置驗算, 橫幅不得蓋住目標
- 開場橫幅與教學泡泡同時出現, 兩段字疊在同一刻(art-lessons P13: 後面的進場前前一個先退場); 泡泡等橫幅退場後再出現
- 字級低於下限: 「等它跳」14px、鍵帽字 13px、角色胸口代數 15px; 關鍵數字「第 N 代」「1 / 7」略小。依新畫布高 720 重算下限(最小約 1/77、關鍵數字約 1/45)

### 小瑕疵
- 全破畫面同時畫三個實心玩家, 規則上場上只有一個「你」; 比照開始畫面的處理(同一人的前後兩刻 / 用幽靈畫法)
- 縮放只監聽 resize, 沒有 orientationchange
- 過關時先下載試玩紀錄, 之後才跑教學收尾送出「教學略過」等事件, 這些事件掉到下一份紀錄或遺失; 下載移到該批次最尾端
- 翹翹板擺動進度、教學完成特效進度的閒置值等於起始值 0(interface-checklist), 改成另給「是否在播」或閒置值不等於起始值
- game.js 取教學錨點、教學標示框兩處 catch 例外沒有 console.error
- sound.js 開頭版本註記仍寫 polish-5

### 待確認(美術判斷)
