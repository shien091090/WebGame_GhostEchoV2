# 接力吉尼 Jelly Jinni 美術規格(polish-12 / 打磨版第 12 輪: 開始畫面改成「主視覺小動畫」)

> index.html 必須宣告 `<meta charset="utf-8">`, 否則 art.js 的中文字串在 file:// 下會變亂碼。
> 用法: `<script src="art/art.js"></script>` 後取用全域 `window.Art`。全部函式自帶 save / restore。
> **兩層座標**:
> - **世界層**(drawBackground、drawPlatform、drawWall、drawSpike、drawPlate、drawLift、drawGate、drawSeesaw、drawGoal、drawGhostPath、drawGhost、drawHook、drawPlayer、drawAim): 美術照**世界座標**畫(世界 853⅓ × 480), **不自己乘倍率**; 電腦版 RD `ctx.scale(1.5, 1.5)` 後呼叫; 觸控模式 RD `scale(2.1) + translate(−camX, −camY)` 後呼叫。
> - **畫面層**(drawTutorial、drawGoalArrow、drawHud、drawLevelBanner、drawPauseMenu、drawSoundIcon、drawTitle、drawUnlockPage、drawEnding): 照**畫面座標** 1280 × 720 畫。觸控模式下 drawHud / drawLevelBanner / drawPauseMenu 由 RD 先放大 1.4 再呼叫(美術函式內**不再**自己放大字, 見「觸控模式」)。

**本輪(polish-12)變動**(函式名、參數照 interface.json, 一個不多一個不少; 沒有新增或刪除函式; drawTitle 的 state 不變):
- **開始畫面 `drawTitle` 動畫整個換掉**: 拿掉上一輪的迷你關卡(地面、尖刺、高台、終點旗、網格、出生光環、死亡白煙、踩頭、碰旗、9 秒循環淡出、胸口代數), 改成發布橫幅式主視覺: 夜空 + 星點, 第 1、2 代幽靈(由小到大)沿一條幽靈藍小圓點路線從左下排到右上, 終點是放大 9 倍的本尊 + 背後柔光。**入場 2 秒演一次 → 4 秒待機循環**(漂浮、接力光點跑過路線、幽靈接棒小跳、本尊接住一壓一彈、眨眼、星星閃爍)。不演玩法、不畫任何標題字
- 開始提示、署名的字樣 / 版位 / 字級 / 呼吸都不變, 只改成入場時淡入(提示 1.4~1.9 秒、署名 0~0.4 秒)
- **其他函式完全不變**: 自測逐條比對上一版的繪圖指令(電腦版 + 觸控模式), 除 drawTitle 外 0 差異

## 邏輯畫布尺寸

**設計寬 1280 × 720**。`Art.canvas.width` 沿用發布時加的依裝置決定寬度(電腦 1280; 觸控裝置照可視區長寬比取 1280~1680 = interface 的 width ~ maxWidth; 網址 `?w=` 可指定), `height` 固定 720。
- 電腦版: 所有東西只畫在設計區 x 0~1280(世界 0~853⅓); HUD 佔 y 0~48, 遊玩區 y 48~720
- 觸控模式: 遊玩畫面用滿畫布 0~CW(CW = `Art.canvas.width`), RD 不做 `translate(OX)`; 全畫面頁 RD 照舊 `translate(OX)`, 底色畫滿 state 給的可見範圍
- 世界座標: 853⅓ × 480, 天花板 y 32, 地面頂 y 456、厚 24 到 480

## 字型

本輪起不使用任何內嵌字型(標題子集字型與 `FontFace` 註冊已刪)。全部文字用現有字型 `"Microsoft JhengHei", "PingFang TC", "Noto Sans TC", sans-serif`。`polish/fonts/` 資料夾留著不動。

## 形狀語言

圓角方塊角色、扁平無漸層的場景塊; 狀態靠「亮色 vs 暗色 + 實心 vs 虛線」切換; 「實心擋路」只有地面材質一種長相; 按鍵提示一律同一種淺色鍵帽(外框色 = 它屬於哪個系統); 遊戲世界裡的文字帶深色描邊; 教學是紙白圓角泡泡 + 細尾巴, 深色粗外框, 裡面深色字; 指向畫面外的東西用該物件的顏色畫圓頭箭頭 + 深色圓底。

## 理念落實

- **P0 辨識度先於好看**: 玩家 = 實心奶白 + 深外框; 幽靈 = 同剪影半透明淡藍 + 虛線外框; 危險只用紅; 每種可互動物件有專屬色 + 專屬記號。開始畫面的三個角色直接用遊玩畫法放大(幽靈 3.3 / 5 倍、本尊 9 倍): 本尊是畫面上唯一實心奶白 + 深外框的東西, 兩代幽靈半透明淡藍 + 虛線外框 + 頭頂實線, 一眼分得出「誰是你」, 也認得出就是遊戲裡那個角色。
- **P1 視覺權重跟著決策迫切度走**: 遊玩中最顯眼的是「現在可以鉤」(綠框 + Z)與瞄準箭頭; HUD 低對比底板; 終點旗方向箭頭只在旗子完全出畫面時出現、小而金色, 不搶角色; 開始畫面沒有標題, 最大最亮的是本尊(佔畫面高 35% + 背後柔光), 幽靈由小到大、由淡到濃把視線一路帶到本尊; 星星小而暗(不透明度 ≤ 0.8 × 閃爍), 開始提示是畫面下方唯一的字, 署名淡色小字。
- **P2 規則上存在的東西畫面上就要存在**: 幽靈頭頂實線(唯一可站的一條邊)、實心 / 單向平台長相不同、HUD 代數圓點分出四種代別; 觸控模式下旗子捲出畫面時, 用方向箭頭讓「目標在那邊」仍看得到; 觸控暫停選單沒選中的那列也畫淡框, 讓「這裡可以點」看得見。
- **P3 一個意義一種長相**: 鍵帽全遊戲同一種; 金色 = 終點 / 達成(旗、過關、方向箭頭; 開始畫面本尊登場與接住的星點和奶白交錯, 不另造新色); 開始畫面的路線就是遊戲內幽靈路線的畫法(幽靈藍小圓點 + 深色襯底 + 終點空心圈); 角色直接用遊戲內剪影(同一組身體 / 腳 / 面罩比例), 只把線寬改成以畫面 px 指定(見「開始畫面」), 不另畫一套吉祥物; 紅色不出現在開始畫面。
- **P4 關鍵區分至少兩條通道**: 開聲 vs 靜音 = 形狀(音波 vs ×)+ 明度; 實心 vs 單向平台 = 亮邊位置 + 下緣鋸齒; 觸控暫停選單選中 vs 沒選中 = 亮框 + 指示箭頭 vs 淡框無箭頭, 字也分亮 / 灰; 開始畫面本尊 vs 幽靈 = 實心 vs 半透明 + 實線外框 vs 虛線外框(虛線還會流動), 再加大小(180 vs 66 / 100 寬)。
- **P7 每個元素都要掙得版面**: 開始畫面只放主視覺(星空、路線、三個角色、柔光)、一行開始提示、一行署名, 不畫標題、鍵帽、胸口代數、進度條、地形; 方向箭頭不畫字; 觸控暫停選單底部只留「點一下 選擇」, 不畫手機上不存在的鍵。
- **P9 以最混亂的那一刻驗收**: 泡泡深色粗外框、Z 鍵帽深色襯框、方向箭頭深色描邊 + 深色圓底, 壓在三代幽靈、亮色平台上都分得出邊; 泡泡避讓用全畫布格點(電腦版 + 觸控 CW 1680)驗過。
- **P13 事件排隊**: 同時只有一顆泡泡(規格保證); 完成特效 0.8 秒內自己縮小淡出。開始畫面的入場一個接一個: 背景(0~0.4)→ 路線逐顆(0.3~1.1)→ 第 1 代(0.45)→ 第 2 代(0.75)→ 本尊(1.05)→ 開始提示(1.4); 待機每輪 4 秒只有一顆光點在跑, 接棒小跳依光點到達順序發生, 本尊接住的星點在 q 1.8 散完後才輪到眨眼(2.60 起, 三人錯開)。
- **P15 回饋強度與份量成正比**: 教學完成是場上唯一「大勾 + 8 顆星點」; 過關才有金框面板; 開始畫面分三級: 幽靈接棒 = 小跳 + 身體閃亮(不加粒子)< 本尊接住 = 一壓一彈 + 光暈脹 1.4 倍 + 6 顆星點 < 本尊登場(只有一次)= 縮放彈出 + 8 顆星點 + 全畫面淡白閃(只有它會動到整個畫面)。
- **P17 進度圖形與數字分工**: 計時器數字給秒數, 量條給「離 10 秒警告段還多遠」(警告段預先染暗紅)。
- **P18 重要資訊不能只存在一瞬間**: 教學完成後它教的鍵仍常駐(HUD 的 Z、幽靈旁 Z、聲音圖示 M、暫停選單鍵帽)。
- **P19 資訊貼著物件**: 泡泡尾巴尖端就在錨點, 被推開避讓時尾巴拉斜仍指著角色 / 幽靈; 標示框直接圈住被講到的物件。
- **P21 示意圖選分岔的例子**: 本輪開始畫面依規格不演玩法、不再當示意圖, 只負責「一眼認出這款遊戲」; 規則的分岔例子(「到不了旗子? 先死一次」→ 踩幽靈頭)交給嵌入式教學在真實關卡上教。開始畫面唯一帶規則意味的是「三代沿一條路線接到本尊」, 只表達接力, 不暗示任何錯的玩法(沒有地形就不會被讀成「這裡可以跳上去」)。
