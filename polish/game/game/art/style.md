# 幽影接力 美術規格(polish-9 / 打磨版第 9 輪: 收成五關, 拿掉起跑哨; 發布前版本)

> index.html 必須宣告 `<meta charset="utf-8">`, 否則 art.js 的中文字串在 file:// 下會變亂碼。
> 用法: `<script src="art/art.js"></script>` 後取用全域 `window.Art`。全部函式自帶 save / restore。
> **兩層座標**:
> - **世界層**(drawBackground、drawPlatform、drawWall、drawSpike、drawPlate、drawLift、drawGate、drawSeesaw、drawGoal、drawGhostPath、drawGhost、drawHook、drawPlayer、drawAim): 美術照**世界座標**畫(世界 853⅓ × 480), **不自己乘 1.5**; RD 每幀 `ctx.save(); ctx.scale(1.5, 1.5)` 後呼叫, 畫完 `restore()`。
> - **畫面層**(drawTutorial、drawHud、drawLevelBanner、drawPauseMenu、drawSoundIcon、drawTitle、drawUnlockPage、drawEnding): 照**畫面座標** 1280 × 720 畫, RD 不放大。

**本輪(polish-9)變動**(函式名、參數照 interface.json, 一個不多一個不少):
- **刪除函式** `drawButton`、`drawCrusher`、`drawWhistleRing`(連同節奏燈、壓板斜紋、解鎖頁哨子圖示、色票 whistle / crusher* / cue*)。`window.Art` 不再匯出它們, RD 不要呼叫
- **只畫設計區**: 拿掉上一版的 `VX / VW` 延伸寫法。背景只畫世界 0 ~ 853⅓; HUD 底、暫停暗幕、失敗暗幕、瞄準霧框、開始畫面 / 解鎖頁 / 全破畫面的底色一律畫畫面 0~1280
- **靜音圖示不用紅**: 靜音 = 喇叭與外框壓暗成淡灰 + 喇叭右側一個淺灰「×」; 開聲 = 白喇叭 + 兩道音波弧線
- **教學泡泡避開聲音圖示**: drawTutorial 新增讀 `avoid`, 規則見「drawTutorial 細節 → 避讓」
- HUD 右塊刪「空白 吹哨」; 關數預設 5; 解鎖頁只有鉤爪; 開場橫幅 newThing 刪 `button` / `final`; 教學 keys 刪 `space`、stage 刪 `button` / `whistle` / `chain` / `slow`(連帶刪掉上一版 chain / slow 泡泡右緣 ≤ 510 的特例)
- 其餘物件(角色、幽靈、平台、牆、尖刺、開關、升降台、門、翹翹板、旗、路線、鉤索、瞄準、暫停選單、開始畫面、全破畫面)畫法照上一版不動

## 邏輯畫布尺寸

**1280 × 720**(`Art.canvas = { width: 1280, height: 720 }`, 固定寬度; interface 的 maxWidth 1680 是發布時的事, 本版沒有依裝置變寬的程式, 不自己加)。
- 畫面座標: HUD 佔 y 0~48(drawHud 自己畫底板), 遊玩區 y 48~720。所有東西只畫在 x 0~1280
- 世界座標: 853⅓ × 480, 世界 (0, 0) = 畫面 (0, 0), 畫面 = 世界 × 1.5。天花板 y 32(= 畫面 48), 地面頂 y 456、厚 24 到 480。背景只畫世界 x 0 ~ 853⅓

## 形狀語言

圓角方塊角色、扁平無漸層的場景塊; 狀態靠「亮色 vs 暗色 + 實心 vs 虛線」切換; 「實心擋路」只有地面材質一種長相; 按鍵提示一律同一種淺色鍵帽(外框色 = 它屬於哪個系統); 遊戲世界裡的文字帶深色描邊; 教學是紙白圓角泡泡 + 細尾巴, 深色粗外框, 裡面深色字。

## 理念落實

- **P0 辨識度先於好看**: 玩家 = 實心奶白 + 深外框; 幽靈 = 同剪影半透明淡藍 + 虛線外框; 危險只用紅; 每種可互動物件有專屬色 + 專屬記號(升降 ↑、門直條、翹翹板圓頭 ↑↓)。放大後角色在畫面上 30 × 42, 胸口代數 15 px + 深描邊。
- **P1 視覺權重跟著決策迫切度走**: 最顯眼的是「現在可以鉤」(綠框 + Z)與瞄準箭頭; HUD 低對比底板; 過關面板放在 HUD 中塊, 不蓋回放中的三代; 聲音圖示是低調深底小方塊, 靜音時再壓暗。
- **P2 規則上存在的東西畫面上就要存在**: 幽靈頭頂實線(唯一可站的一條邊)、實心 / 單向平台長相不同、HUD 代數圓點分出「你 / 場上幽靈 / 已消失 / 還沒出場」、坑底警示照五關坑位。
- **P3 一個意義一種長相**: 鍵帽全遊戲同一種; Z 一律鉤爪色框; 「綠 = 做到了」只在教學完成; **紅只代表危險, 本輪把靜音圖示上的紅斜線 / 紅框拿掉**, 靜音改用灰白明暗。整頁畫面與橫幅的小圖全部呼叫遊戲內畫法, 給規則上成立的 state。
- **P4 關鍵區分至少兩條通道**: 開聲 vs 靜音 = 形狀(音波弧線 vs ×)+ 明度(白 vs 壓暗灰); 實心 vs 單向平台 = 亮邊位置 + 下緣鋸齒; 教學 vs 遊戲物件 = 明度反轉 + 帶尾巴的外形; 開關 lift vs gate = 顏色 + 記號(↑ vs 直條)。
- **P7 每個元素都要掙得版面**: 刪掉的關卡物件(按鈕、壓板、節奏燈、哨音波紋)整組移除, HUD 右塊只剩鉤爪; 瞄準暫停框只留霧框 + 四角括號; 開始畫面只放遊戲名、小圖、開始提示、署名。
- **P9 以最混亂的那一刻驗收**: 泡泡深色粗外框、Z 鍵帽深色襯框、等它跳深底, 壓在三代幽靈、亮色平台上都分得出邊; 泡泡避讓用全畫布格點(每 40 px × 四種方位 × 九階段)驗過。
- **P13 事件排隊**: 同時只有一顆泡泡(規格保證); 完成特效 0.8 秒內自己縮小淡出到完全消失。
- **P15 回饋強度與份量成正比**: 教學完成是場上唯一「大勾 + 8 顆星點」的演出, 範圍只到泡泡外 40 px; 過關才有金框面板。
- **P17 進度圖形與數字分工**: 計時器數字給秒數, 量條給「離 10 秒警告段還多遠」(警告段預先染暗紅)。
- **P18 重要資訊不能只存在一瞬間**: 教學完成後它教的鍵仍常駐: HUD(Z 鉤爪)、幽靈旁(Z)、聲音圖示(M)、暫停選單(↑↓ 空白 Esc)。
- **P19 資訊貼著物件**: 泡泡尾巴尖端就在錨點; 被推開避讓聲音圖示時尾巴拉斜, 尖端仍指著角色 / 幽靈; 講到某物件時用標示框直接圈住它。
- **P21 示意圖選分岔的例子**: 開始畫面小圖用「實心的 2 號站在 62% 不透明的 1 號幽靈頭上、一起離地」, 讓「踩著前一刻的自己往上」與「兩個玩家一起玩」分得開(實心的只有一個)。

### drawHud 細節(版位固定, 整條 1280 × 48, 不透明底; 各塊中線 y 24)

- **中塊**(置中, x 540~740): phase === 'play' 時畫計時器(單行): 時鐘圖示 + 剩餘秒數 24 px(無條件進位)+「秒」13 px + 120 × 8 量條(x 620~740, 左端 10 秒段預染暗紅 + 分界刻度); ≤ 10 秒全轉紅, 每秒跳號時數字放大 15% 一下。dying / win / lose 不畫
- **右塊**(貼右緣 1268, 靠右): hookUnlocked → 「[Z] 鉤爪」+ hookMax 個 22 × 30 鉤子格(剩餘的亮、用掉的虛線暗)。本輪刪「空白 吹哨」

### drawTutorial 細節(畫面座標)

state: `stage`(9 種 id)、`text`(一行字)、`keys`(陣列: 'left' / 'right' / 'jump' / 'Z' / 'esc', 最多 3 個)、`pressed`(與 keys 等長的布林陣列)、`ax`, `ay`(尾巴尖端)、`place`('above' / 'below' / 'left' / 'right')、`tail`(尾巴長度)、`pop`(0~1)、`finishing`(bool)、`done`(0~1, 只在 finishing 時讀)、`mark`({x, y, w, h} 或 null)、`avoid`({x, y, w, h}, 固定 (1222, 50, 52, 52))。

- **版面**: 泡泡高 52, 左右內距 14; 內容由左到右「文字(16 px 粗體深色)→(head 階段)向下小箭頭 → 鍵帽(26 高, 間距 6)」, 文字與鍵帽間 10。寬 80~300(超過 300 時文字壓縮到放得下)
- **位置**: 尾巴尖端 = (ax, ay)。above: 泡泡底緣 = ay − tail、水平置中於 ax; below: 泡泡頂緣 = ay + tail; left: 泡泡右緣 = ax − tail、垂直置中於 ay; right: 泡泡左緣 = ax + tail。之後左右夾在 x 12~1268、上下夾在 y 56~708。尾巴底寬 14, tail 再長也只拉長。不自動上下翻轉(遊戲端已決定 above / below)
- **left / right 放不下時換邊**: left 時若 ax − tail − 寬 < 12, 改 right 並把錨點往右挪 30(角色畫面寬); right 放不下同理改 left、錨點往左 30。避免夾邊後泡泡蓋住角色
- **避讓(本輪新增)**: 泡泡本體排好、夾進畫布之後, 若和 `avoid` 重疊:
  - above / below: 泡泡水平往左推到右緣 = avoid.x − 6(1216), 垂直不動(左緣不小於 12)
  - left / right: 泡泡往下推到頂緣 = avoid.y + avoid.h + 6(108)
  - 尾巴尖端仍在 (ax, ay); 尾巴根部夾在近端邊上、根部兩側離泡泡角至少 12, 尖端在泡泡外側時尾巴自然變斜
  - pop 彈出縮放、完成特效(閃綠、大勾、星點、縮小淡出)都以推開後的泡泡為準
  - avoid 缺漏或寬高 ≤ 0 時不避讓
- **鍵帽**: 'left' ← / 'right' → / 'jump' ↑ / 'Z' / 'esc' 方鍵帽(Esc 依字寬略寬)。Z 外加鉤爪色框(與幽靈旁 Z 一樣); ← → ↑ Esc 無框。鍵帽下方有一條深色厚度
- **已按過(pressed[i] = true)**: 鍵帽底換淡綠、邊換深綠、右上角綠底白勾小圓; 由 false 變 true 的那一刻彈一下(0.26 秒, 上浮 4 px + 放大 15%; 美術內部計時, RD 不必傳)
- **出現(finishing=false, pop 0 → 1)**: 從尾巴尖端長出來, 彈性縮放(最大約 1.10 倍), 不透明度在 pop 0~0.33 從 0 到 1
- **完成(finishing=true, done 0 → 1)**:
  - 0~0.45: 泡泡底疊綠光一閃(最亮在 0.22), 外框換綠; 之後保留淡綠底
  - 0~0.25: 泡泡中央彈出大勾勾(綠圓 r 18 + 白勾)
  - 鍵帽依序彈一下: 第 i 顆在 done = 0.1·i ~ 0.1·i + 0.2
  - 0.08~1: 8 顆小星點(綠 / 白交錯)從泡泡中心往外散到泡泡外約 36~40 px 並淡出
  - 0.55~1: 泡泡與大勾勾往中心縮到 45%、淡出; finishing 且 done ≥ 1 時什麼都不畫
- **標示框(mark 非 null)**: 沿 mark 畫圓角框(mark 已含外擴), 紙白虛線(2.2 寬, 段 8 / 5)+ 深色襯底, 0.9 秒一次脈動再外擴 0~4 px, 虛線緩慢繞行。跟著泡泡一起出現 / 淡出。畫在泡泡之下

自測實測(一般泡泡本體): 第 1 階段 x 12~201、y 568~620(不碰 avoid, 照原排); spec 例幽靈 (760, 120) → 錨點 (1155, 174) above tail 56 → 泡泡推成右緣 1216、y 66~118, 尾巴斜指錨點。全畫布格點(錨點每 40 px × 4 種方位 × tail 16 / 56 × 9 階段, 共 39168 個)泡泡本體碰 avoid 0 次、出 x 12~1268 / y 56~708 0 次。
