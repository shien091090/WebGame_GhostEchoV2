## 形狀語言

圓角方塊角色、扁平無漸層的場景塊; 狀態靠「亮色 vs 暗色 + 實心 vs 虛線」切換; 「實心擋路」只有地面材質一種長相; 按鍵提示一律同一種淺色鍵帽(外框色 = 它屬於哪個系統; 世界層與畫面層放大後同尺寸級); 量條一律「深色常駐軌道 + 預先染暗紅的警告段 + 分界刻度」; 遊戲世界裡的文字帶深色描邊; 教學是紙白圓角泡泡 + 細尾巴, 深色粗外框, 裡面深色字。

## 理念落實

- **P0 辨識度先於好看**: 玩家 = 實心奶白 + 深外框; 幽靈 = 同剪影半透明淡藍 + 虛線外框; 危險只用紅; 每種可互動物件有專屬色 + 專屬記號(升降 ↑、門直條、按鈕圓頂斜紋)。本輪放大 1.5 倍後角色在畫面上 30 × 42, 胸口代數 15 px(世界 10)+ 深描邊。
- **P1 視覺權重跟著決策迫切度走**: 最顯眼的是「現在可以鉤」(綠框 + Z)、瞄準箭頭、壓板量條與節奏燈; HUD 低對比底板; 過關面板改放在 HUD 中塊(計時器不畫的位置), 不蓋回放中的三代。
- **P2 規則上存在的東西畫面上就要存在**: 幽靈頭頂實線(唯一可站的一條邊)、實心 / 單向平台長相不同、壓板量條軌道與燈座常駐、HUD 代數圓點分出「你 / 場上幽靈 / 已消失 / 還沒出場」。坑底警示照各關新坑位(第 1 關只有 400~480, 第 6 關沒有坑)。
- **P3 一個意義一種長相**: 鍵帽全遊戲同一種(教學泡泡、幽靈旁、節奏燈旁、HUD、暫停選單、開始畫面); 世界層鍵帽 11 高 × 1.5 ≈ 畫面 16.5, 和畫面層 HUD 的 18 高同一級; Z 一律鉤爪色框、吹哨的「空白」在「現在該吹」的地方一律綠框; 「綠 = 對了」只在節奏燈 ok 與教學完成。整頁畫面與橫幅的小圖全部呼叫遊戲內畫法, 給規則上成立的 state。
- **P4 關鍵區分至少兩條通道**: 節奏燈 = 顏色 + 記號(勾 / 沙漏 / 叉)+ 動態(wait 慢閃); 開關 vs 按鈕 = 顏色 + 外形(平踏板 vs 圓頂); 實心 vs 單向平台 = 亮邊位置 + 下緣鋸齒; 教學 vs 遊戲物件 = 明度反轉 + 帶尾巴的外形; 靜音 = 喇叭聲波消失 + 紅斜線 + 外框轉紅。
- **P7 每個元素都要掙得版面**: 節奏燈拿掉外光暈(燈只剩 5.5 半徑, 光暈不再掙得空間, 靠顏色 + 記號 + 慢閃已夠); 瞄準暫停框只留霧框 + 四角括號; 開始畫面只放遊戲名、小圖、開始提示、署名。
- **P9 以最混亂的那一刻驗收**: 泡泡深色粗外框、Z 鍵帽深色襯框、等它跳深底, 壓在三代幽靈、壓板斜紋、亮色平台上都分得出邊。
- **P13 事件排隊**: 同時只有一顆泡泡(規格保證); 完成特效 0.8 秒內自己縮小淡出到完全消失。
- **P15 回饋強度與份量成正比**: 教學完成是場上唯一「大勾 + 8 顆星點」的演出, 範圍只到泡泡外 40 px; 吹哨波紋外緣 ≤ 28(世界); 過關才有金框面板。
- **P17 進度圖形與數字分工**: 計時器數字給秒數, 量條給「離 10 秒警告段還多遠」(警告段預先染暗紅); 壓板量條給「離最後 0.3 秒還多遠」, 刻度每 0.3 秒一道, 依柱長判斷 1.7 / 1.2 秒。
- **P18 重要資訊不能只存在一瞬間**: 教學完成後它教的鍵仍常駐在 HUD(Z 鉤爪、空白 吹哨)、物件旁(Z、空白)、聲音圖示(M)、暫停選單(↑↓ 空白 Esc)。
- **P19 資訊貼著物件**: 泡泡尾巴尖端就在錨點(第 5 階段改成角色側邊的橫向尾巴); 講到某物件時再用標示框直接圈住它; Z 鍵帽貼在可鉤幽靈頭頂, 空白鍵帽貼在節奏燈旁。
- **P21 示意圖選分岔的例子**: 開始畫面小圖用「實心的 2 號站在 62% 不透明的 1 號幽靈頭上、一起離地」(地上一個隨高度縮小的影子), 讓「踩著前一刻的自己往上」與「兩個玩家一起玩」分得開(實心的只有一個)。

### drawTutorial 細節(畫面座標)

state: `stage`(13 種 id)、`text`(一行字)、`keys`(陣列: 'left' / 'right' / 'jump' / 'Z' / 'space' / 'esc', 最多 3 個)、`pressed`(與 keys 等長的布林陣列)、`ax`, `ay`(尾巴尖端)、`place`('above' / 'below' / 'left' / 'right')、`tail`(尾巴長度)、`pop`(0~1)、`finishing`(bool)、`done`(0~1, 只在 finishing 時讀)、`mark`({x, y, w, h} 或 null)。

- **版面**: 泡泡高 52, 左右內距 14; 內容由左到右「文字(16 px 粗體深色)→(head 階段)向下小箭頭 → 鍵帽(26 高, 間距 6)」, 文字與鍵帽間 10。寬 80~300(超過 300 時文字壓縮到放得下)。
- **位置**: 尾巴尖端 = (ax, ay)。above: 泡泡底緣 = ay − tail、水平置中於 ax; below: 泡泡頂緣 = ay + tail、水平置中於 ax; **left: 泡泡右緣 = ax − tail、垂直置中於 ay; right: 泡泡左緣 = ax + tail、垂直置中於 ay**(尾巴從泡泡側邊伸出, 橫向細三角)。之後左右夾在 x 12~1268、上下夾在 y 56~708, 夾邊後尾巴仍指向錨點。尾巴底寬 14, tail 再長也只拉長。不自動上下翻轉(遊戲端已決定 above / below)。
- **left / right 放不下時換邊**: left 時若 ax − tail − 寬 < 12(角色貼畫布左緣), 改 right 並把錨點往右挪 30(角色畫面寬, 尾巴改指角色右緣); right 時放不下同理改 left、錨點往左 30。避免夾邊後泡泡蓋住角色。
- **第 7 關節奏燈**: `stage` 為 chain / slow 且 place 為 below 時, 泡泡右緣夾在 ≤ 510(泡泡 x 約 230~510、y 190~242), 不壓頂層右段等著的角色。
- **鍵帽**: 'left' ← / 'right' → / 'jump' ↑ / 'Z' / 'esc' 方鍵帽(Esc 依字寬略寬); 'space' 寬鍵帽「空白」(最窄 46)。Z 外加鉤爪色框、空白外加綠燈色框(與幽靈旁 Z、節奏燈旁空白一樣); ← → ↑ Esc 無框。鍵帽下方有一條深色厚度。
- **已按過(pressed[i] = true)**: 鍵帽底換淡綠、邊換深綠、右上角綠底白勾小圓; 由 false 變 true 的那一刻彈一下(0.26 秒, 上浮 4 px + 放大 15%; 美術內部計時, RD 不必傳)。
- **出現(finishing=false, pop 0 → 1)**: 從尾巴尖端長出來, 彈性縮放(最大約 1.10 倍), 不透明度在 pop 0~0.33 從 0 到 1。
- **完成(finishing=true, done 0 → 1)**:
  - 0~0.45: 泡泡底疊綠光一閃(最亮在 0.22), 外框換綠; 之後保留淡綠底
  - 0~0.25: 泡泡中央彈出大勾勾(綠圓 r 18 + 白勾)
  - 鍵帽依序彈一下: 第 i 顆在 done = 0.1·i ~ 0.1·i + 0.2
  - 0.08~1: 8 顆小星點(綠 / 白交錯)從泡泡中心往外散到泡泡外約 36~40 px 並淡出
  - 0.55~1: 泡泡與大勾勾往中心縮到 45%、淡出; finishing 且 done ≥ 1 時什麼都不畫
- **標示框(mark 非 null)**: 沿 mark 畫圓角框(mark 已含外擴), 紙白虛線(2.2 寬, 段 8 / 5)+ 深色襯底, 0.9 秒一次脈動再外擴 0~4 px, 虛線緩慢繞行。跟著泡泡一起出現 / 淡出。畫在泡泡之下。
