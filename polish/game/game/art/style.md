> index.html 必須宣告 `<meta charset="utf-8">`, 否則 art.js 的中文字串在 file:// 下會變亂碼。
> 用法: `<script src="art/art.js"></script>` 後取用全域 `window.Art`。全部函式自帶 save / restore。
> **兩層座標**:
> - **世界層**(drawBackground、drawPlatform、drawWall、drawSpike、drawPlate、drawLift、drawGate、drawSeesaw、drawGoal、drawGhostPath、drawGhost、drawHook、drawPlayer、drawAim): 美術照**世界座標**畫(世界 853⅓ × 480), **不自己乘倍率**; 電腦版 RD `ctx.scale(1.5, 1.5)` 後呼叫; 觸控模式 RD `scale(2.1) + translate(−camX, −camY)` 後呼叫。
> - **畫面層**(drawTutorial、drawGoalArrow、drawHud、drawLevelBanner、drawPauseMenu、drawSoundIcon、drawTitle、drawUnlockPage、drawEnding): 照**畫面座標** 1280 × 720 畫。觸控模式下 drawHud / drawLevelBanner / drawPauseMenu 由 RD 先放大 1.4 再呼叫(美術函式內**不再**自己放大字, 見「觸控模式」)。

**本輪(polish-10)變動**(函式名、參數照 interface.json, 一個不多一個不少):

## 邏輯畫布尺寸

**設計寬 1280 × 720**。`Art.canvas.width` 沿用發布時加的依裝置決定寬度(電腦 1280; 觸控裝置照可視區長寬比取 1280~1680 = interface 的 width ~ maxWidth; 網址 `?w=` 可指定), `height` 固定 720。
- 電腦版: 所有東西只畫在設計區 x 0~1280(世界 0~853⅓); HUD 佔 y 0~48, 遊玩區 y 48~720
- 觸控模式: 遊玩畫面用滿畫布 0~CW(CW = `Art.canvas.width`), RD 不做 `translate(OX)`; 全畫面頁 RD 照舊 `translate(OX)`, 底色畫滿 state 給的可見範圍
- 世界座標: 853⅓ × 480, 天花板 y 32, 地面頂 y 456、厚 24 到 480

## 形狀語言

圓角方塊角色、扁平無漸層的場景塊; 狀態靠「亮色 vs 暗色 + 實心 vs 虛線」切換; 「實心擋路」只有地面材質一種長相; 按鍵提示一律同一種淺色鍵帽(外框色 = 它屬於哪個系統); 遊戲世界裡的文字帶深色描邊; 教學是紙白圓角泡泡 + 細尾巴, 深色粗外框, 裡面深色字; 指向畫面外的東西用該物件的顏色畫圓頭箭頭 + 深色圓底。

## 理念落實

- **P0 辨識度先於好看**: 玩家 = 實心奶白 + 深外框; 幽靈 = 同剪影半透明淡藍 + 虛線外框; 危險只用紅; 每種可互動物件有專屬色 + 專屬記號。開始畫面的三代直接用遊玩畫法放大 3 倍, 1、2 代是幽靈(62% 不透明 + 虛線框)、3 代是實心本尊, 一眼分得出「誰是你」。
- **P1 視覺權重跟著決策迫切度走**: 遊玩中最顯眼的是「現在可以鉤」(綠框 + Z)與瞄準箭頭; HUD 低對比底板; 終點旗方向箭頭只在旗子完全出畫面時出現、小而金色, 不搶角色; 開始畫面最亮的是標題與跳接動態, 署名淡色小字。
- **P2 規則上存在的東西畫面上就要存在**: 幽靈頭頂實線(唯一可站的一條邊)、實心 / 單向平台長相不同、HUD 代數圓點分出四種代別; 觸控模式下旗子捲出畫面時, 用方向箭頭讓「目標在那邊」仍看得到; 觸控暫停選單沒選中的那列也畫淡框, 讓「這裡可以點」看得見。
- **P3 一個意義一種長相**: 鍵帽全遊戲同一種; 金色 = 終點(旗、過關、方向箭頭、碰旗星點); 開始畫面的跳接虛線弧用遊戲內幽靈路線的小圓點 + 終點空心圈; 整頁畫面與橫幅的小圖全部呼叫遊戲內畫法。
- **P4 關鍵區分至少兩條通道**: 開聲 vs 靜音 = 形狀(音波 vs ×)+ 明度; 實心 vs 單向平台 = 亮邊位置 + 下緣鋸齒; 觸控暫停選單選中 vs 沒選中 = 亮框 + 指示箭頭 vs 淡框無箭頭, 字也分亮 / 灰。
- **P7 每個元素都要掙得版面**: 開始畫面只放標題、跑道動態、開始提示、署名; 方向箭頭不畫字; 觸控暫停選單底部只留「點一下 選擇」, 不畫手機上不存在的鍵。
- **P9 以最混亂的那一刻驗收**: 泡泡深色粗外框、Z 鍵帽深色襯框、方向箭頭深色描邊 + 深色圓底, 壓在三代幽靈、亮色平台上都分得出邊; 泡泡避讓用全畫布格點(電腦版 + 觸控 CW 1680)驗過。
- **P13 事件排隊**: 同時只有一顆泡泡(規格保證); 完成特效 0.8 秒內自己縮小淡出。開始畫面的跳接一次只有一個人在跳, 被踩的人扁一下後跳的人才淡出, 下一段虛線弧才浮現。
- **P15 回饋強度與份量成正比**: 教學完成是場上唯一「大勾 + 8 顆星點」; 過關才有金框面板; 開始畫面碰旗只有 6 顆小星點 + 旗子小晃。
- **P17 進度圖形與數字分工**: 計時器數字給秒數, 量條給「離 10 秒警告段還多遠」(警告段預先染暗紅)。
- **P18 重要資訊不能只存在一瞬間**: 教學完成後它教的鍵仍常駐(HUD 的 Z、幽靈旁 Z、聲音圖示 M、暫停選單鍵帽)。
- **P19 資訊貼著物件**: 泡泡尾巴尖端就在錨點, 被推開避讓時尾巴拉斜仍指著角色 / 幽靈; 標示框直接圈住被講到的物件。
- **P21 示意圖選分岔的例子**: 開始畫面用「1 代踩 2 代頭 → 2 代踩 3 代頭 → 只有實心的 3 代碰到旗子」, 讓「踩著前幾代的自己往上」與「幾個玩家一起跑」分得開(實心的只有一個, 幽靈碰完就淡出)。
