# 幽影接力 美術規格(polish-4 / 打磨版第 4 輪: 七關, 能力解鎖制)

> index.html 必須宣告 `<meta charset="utf-8">`, 否則 art.js 的中文字串在 file:// 下會變亂碼。
> 用法: `<script src="art/art.js"></script>` 後取用全域 `window.Art`。全部函式自帶 save / restore。
> **本輪(polish-4)只改 drawSeesaw**: 新增 `swing`; 兩端記號從實心三角改成成對的圓頭箭頭; 擺動特效從「往上伸的三條白線」改成扁橢圓氣流圈 + 灰塵圓點, 板子回平時略過頭再彈回(H47: 上一版被讀成尖刺)。關卡卡片 seesaw / final 小圖改傳擺動中的 swing。其餘函式、色票、版位不變; 說明頁沒有畫翹翹板, 不受影響。
>
> 以下為 polish-3 的變動紀錄: 沿用 polish-2 的色票、形狀語言與物件畫法。本版變動: **drawHud** 加剩餘時間計時器(`timeLeft`、`timeMax`), 「C 吹哨」「R 重來」改成上下疊放讓出計時器版位; **drawGhost** 加 `hookAir`(幽靈站地上時 Z 鍵帽下加「↑等它跳」); **drawCrusher** 加 `cue` 節奏燈, 量條縮短讓出燈位, 可畫任意長度(第 6 關約 1100 高); **drawLevelIntro** 加 newThing `'final'`; 說明第 1 頁示意圖加 HUD 計時器; 關卡數預設 7。關卡卡片 `'hook'` 小圖修正: 射出中的角色在空中, 依新規則 23 幽靈不再畫可鉤綠框。

## 邏輯畫布尺寸

720 × 1280。HUD 佔上方 y 0~100(drawHud 自己畫底板), 遊戲區 y 100~1280(y 100 是天花板)。

## 形狀語言

圓角方塊角色、扁平無漸層的場景塊; 狀態靠「亮色 vs 暗色 + 實心 vs 虛線」切換; 「實心擋路」只有地面材質一種長相; 「會開的東西」開著時只剩「虛線框 + 上下框頭」; 「按鈕 / 壓板」共用斜紋帶; 按鍵提示一律同一種淺色鍵帽(外框色 = 它屬於哪個系統); 量條一律「深色常駐軌道 + 預先染暗紅的警告段 + 分界刻度」; 所有文字帶深色描邊。

## 理念落實

- P0: 玩家 = 實心奶白 + 深外框; 幽靈 = 同剪影半透明淡藍 + 虛線外框; 危險只用紅; 可互動物件各有專屬色 + 專屬記號(升降台開關 ↑ / 門開關直條 / 按鈕圓頂 + 斜紋 / 翹翹板成對圓頭箭頭 ↓↑)。**翹翹板與陷阱分開(H47)**: 「尖角朝上」與紅 / 橘紅只屬於尖刺與壓板; 翹翹板的記號與擺動特效全部是圓頭線、扁橢圓、圓點, 顏色只用冷灰藍與白, 縮到 50% 也沒有一排朝上的尖。節奏燈四態各有一個記號(✓ / 沙漏 / ✕ / 暗), 計時器進警告區整組變紅。
- P1: 最顯眼的是「現在可以鉤」(鉤爪色粗框 + Z 鍵帽)、瞄準箭頭、壓板量條與節奏燈(都放在角色眼睛高度); 計時器在 HUD, 平時是中性淺色, 只有剩 10 秒才轉紅並在跳號時放大一下; 路線、背景網格、升降台軌道壓在低不透明度。
- P2: 幽靈「只有頭頂可站」畫成頭頂實線; 實心平台用地面材質、單向平台保留下緣鋸齒; 壓板量條軌道與節奏燈**燈座**常駐(沒在倒數 / 沒亮時也看得到這根柱子有計時、有燈); 新規則「站在地上的幽靈幾乎鉤不高」以「↑等它跳」貼在 Z 鍵帽下呈現; 每代 60 秒上限以 HUD 計時器呈現。
- P3: 鉤爪色只代表鉤爪, 壓板色只代表按鈕與壓板, 綠燈色只代表「現在吹哨接得上」; 鍵帽全遊戲同一樣式(HUD、幽靈旁 Z、角色旁 Z / X、壓板燈旁 C、說明頁); 「量條 + 預染暗紅警告段 + 刻度」在壓板倒數與 HUD 計時器共用; 說明頁、卡片、解鎖頁的物件全部呼叫遊戲內函式並給規則上成立的 state(本版修正: 關卡卡片鉤爪小圖射出中的角色在空中, 幽靈不畫可鉤框)。
- P4: 翹翹板特效 vs 尖刺 = 形狀(圓弧 / 圓點 vs 三角排)+ 顏色(冷灰白 vs 紅)兩條通道, 動態上氣流圈往上飄走淡出、尖刺不動; 節奏燈四態 = 顏色 + 燈內記號兩條通道; 計時器警告 = 顏色 + 量條進入預染紅段 + 跳號脈動; 按鈕 vs 開關 = 顏色 + 外形; 實心 vs 單向平台 = 明度 + 底緣; 玩家 vs 幽靈 = 不透明度 + 外框線型。
- P7: HUD 只放代數、關卡、已解鎖能力、剩餘時間、按鍵提示、靜音; 沒解鎖的能力整塊不畫。「等它跳」只在可鉤且幽靈著地時出現; C 鍵帽只在綠燈時出現。
- P9: 線類元素都有深色襯底; 鍵帽、「等它跳」小牌、瞄準提示框、節奏燈燈座都自帶深色底, 壓在三代回放、壓板斜紋或幽靈上照樣讀得到。
- P13: 過關 / 失敗面板只有一塊; 這兩個階段不畫計時器, 不疊。
- P15: 吹哨波紋是場上唯一的外擴大環(翹翹板氣流圈是扁橢圓、往上飄而不是原地外擴, 只有 0.3 秒, 不和它同形); 鉤索 0.15 秒細線; 壓板警告閃爍只在最後 0.3 秒; 計時器只在跳號後 0.25 秒放大 22%, 不閃整個 HUD。
- P17: 計時器數字給精確秒數; 量條給數字給不了的「離警告區(最後 10 秒)還多遠」: 左端 10 秒段預染暗紅 + 分界刻度, 量條縮進紅段 = 進入警告(量條長度本身是規格指定的總進度, 已知與 P17「不重述」有張力, 靠警告段讓它有自己的工作)。壓板量條同理, 每 0.3 秒一格、最後 0.3 秒預染紅。
- P18: 鉤爪次數、代數、剩餘時間常駐 HUD。
- P19: Z 鍵帽與「等它跳」貼在幽靈框外; 「Z 射出 / X 取消」貼角色頭頂; 壓板量條、節奏燈、C 鍵帽同一列畫在壓板下緣上方、玩家鑽過去時的視線高度。
- P21: 說明第 2 頁並排「跳不上(叉)」與「掉坑(勾)」; 第 5 頁畫出 2 號幽靈腳下看不見的 1 號; 起跑哨解鎖頁並排吹哨前後。
