## 新手教學

### 共通規則
- **同時只顯示一個提示泡泡**。主線階段(第 1~8 階段)依編號順序進行: 前一階段完成(且完成特效播完、再隔 0.4 秒)後, 下一階段在它的出現條件成立時出現
- **不和開場橫幅同時出現**: 表中寫「橫幅後」的階段, 出現時機是「開場橫幅完全消失後 0.3 秒」, 即第 1 代出生後 1.8 秒; 沒有橫幅的嘗試(重來、失敗重試)是出生後 0.5 秒。橫幅還在時, 任何泡泡(含條件式)都等它消失

- `stage`: 階段 id(`move` / `die` / `head` / `hookAim` / `hookFire` / `gate` / `lift` / `seesaw` / `stuck`)
- `text`: 泡泡文字(遊戲端給字串, 照上表)
- `keys`: 按鍵圖示陣列, 值為 `'left'` `'right'` `'jump'` `'Z'` `'esc'`; 長度 0~3, 沒有按鍵時空陣列
- `pressed`: 與 `keys` 等長的布林陣列(只有第 1 階段會變 true)
- `ax`, `ay`: 錨點(尾巴尖端, 畫面座標 = 世界錨點 × 1.5)
- `place`: `'above'` | `'below'` | `'left'` | `'right'`
- `tail`: 尾巴長度 px(錨點到泡泡近端邊緣): 16 / 48 / 56
- `pop`: 0~1, 出現彈出進度(0.25 秒到 1, 之後保持 1)
- `finishing`: 布林, 完成特效正在播
- `done`: 0~1, 完成特效進度(finishing 為 true 時才有意義; 完成瞬間 0, 0.8 秒到 1, 到 1 後不再呼叫; finishing 為 false 時傳 0)
- `mark`: 標示框 `{ x, y, w, h }`(畫面座標, 已含外擴)或 `null`
- `avoid`: 要避開的框 `{ x, y, w, h }`; 電腦版固定 `{ x: 1222, y: 50, w: 52, h: 52 }`, 觸控模式為選單鍵避讓框; 美術照「共通規則 → 避開聲音開關圖示」推開泡泡
- `avoid2`(上一版程式已有, 本輪補進規格): 電腦版 `null`; 觸控模式為方向鍵外接框, 規則見「觸控模式」
- `scale`(本輪新增): 泡泡整體放大倍率, 電腦版 1、觸控模式 1.4(高、字、最寬、鍵帽、特效距離都乘; `tail` 遊戲端已乘好, 美術不再乘)
- `bounds`(本輪新增): 泡泡本體的夾邊範圍 `{ x, y, w, h }`; 電腦版 `{ x: 12, y: 56, w: 1256, h: 652 }`(= 原本寫死的 12 ~ 1268、56 ~ 708), 觸控模式 `{ x: 12, y: 75.2, w: CW − 24, h: 632.8 }`
- 座標: 電腦版是畫面座標 0~1280; 觸控模式是畫布座標 0~CW(遊戲端不做 translate(OX))

## 概述
走到終點前必須先死, 死掉的自己變成不斷重演的幽靈, 下一個自己踩它、搭它、鉤它, 讓它守住開關、壓翹翹板, 三個人內摸到旗子。
五關, 每關多一樣新東西; 過第 1 關解鎖鉤爪。

## 核心循環
看關卡 → 第 1 代替第 2 代鋪路(站位、跳、守開關)後死去 → 第 2 代利用第 1 代幽靈上到高處, 再替第 3 代鋪路後死去 → 第 3 代只看得到第 2 代, 利用它到終點 → 看三代合力回放 → 下一關多一樣新東西。

## 規則
以下座標、長度、速度都是世界座標。

### 基本
1. 每關單一畫面, 世界 853⅓ × 480, 放大 1.5 倍顯示, 不捲動。座標以左上為原點, y 向下
2. 角色左右走(← →)、跳躍(只有 ↑); 受重力, 落地才能起跳(地面、平台、升降台、翹翹板、幽靈頭頂都算落地)
3. 地面為實心(從下方撞到會停住、頂面可站); 空中平台、升降台、翹翹板為單向平台: 從下方可穿過, 從上方落下時會站上去。牆、關著的門為實心, 擋住角色
4. 角色掉出世界下緣(y 480)即死亡; 碰到尖刺即死亡; 角色左右不能走出世界(0 ~ 853⅓)。**世界 y 32(HUD 下緣)是天花板**: 角色頭頂到達 y 32 時停在那裡, 往上的速度歸零(幽靈照紀錄重播, 不受影響)
5. 共三代角色, 第 1 代開局出生在出生點(每關都是 x 30, y 428; 腳底 456)
6. 每代從出生到死亡的每一幀都被記錄(60 幀/秒): 位置、朝向、動作狀態、是否著地、鉤索兩端(只在鉤索顯示時間內)、「這一幀上一代幽靈播到第幾幀」(第 1 代記空)。瞄準暫停、暫停選單期間時間不前進、不記錄。錄製達 60 秒時該代自動死亡(cause timeout)
   - 6a. 剩餘時間顯示: HUD 顯示「這一代還剩幾秒」(60 − 已錄製秒數, 無條件進位成整數秒, 並配一條隨時間縮短的量條)。剩 10 秒起變警告色; 剩 5、4、3、2、1 秒時各響一聲 `timeTick`。瞄準、暫停時停住。死亡演出、過關回放、失敗畫面時不顯示
7. 某代死亡後播放 0.6 秒死亡演出, 接著下一代在出生點出生; 升降台、門、翹翹板回到初始狀態
8. 新一代出生的同一幀, 上一代的紀錄從第 0 幀開始以「幽靈」重播; 播完最後一幀後立刻從第 0 幀重新開始, 無限循環
9. 場上只存在「上一代」的幽靈: 操控第 2 代時只有第 1 代幽靈; 操控第 3 代時只有第 2 代幽靈, 第 1 代幽靈完全消失(不顯示、不可踩、不可鉤、不壓開關、不觸發翹翹板)
10. 幽靈不受尖刺、坑洞、門、牆、升降台、翹翹板、天花板影響, 純粹照紀錄重播; 紀錄中帶鉤索的幀, 幽靈連同鉤索一起顯示
11. 幽靈只有頭頂可以站。站上去的條件: 這一幀角色垂直速度 ≥ 0、水平與幽靈重疊, 且「上一幀角色腳底 ≤ 上一幀幽靈頭頂」、「這一幀角色腳底 ≥ 這一幀幽靈頭頂」(從上方落下來)。幽靈這一幀是瞬移(循環接回第 0 幀)時, 「上一幀幽靈頭頂」改用這一幀的頭頂。角色身體和幽靈重疊時, 幽靈怎麼移動都不會把角色頂上去; 出生當下角色一律站在地面上
12. 站在幽靈頭上時, 角色跟著幽靈移動(水平位移相加, 腳底每幀貼齊幽靈頭頂); 可以從幽靈頭上起跳(初速只有跳躍初速, 不加幽靈的速度); 水平走出幽靈頭頂範圍即離開
13. 幽靈循環從最後一幀跳回第 0 幀時, 站在它頭上的角色不跟著瞬移, 改為進入空中狀態
13a. 站在幽靈頭上被帶著往上時, 若角色頭頂碰到天花板(y 32), 角色停在那裡、離開幽靈、進入空中(垂直速度歸零), 之後照重力落下; 幽靈照紀錄繼續動(身體重疊時不會把角色頂上去, 同規則 11)。第 5 關騎被翹翹板彈起的幽靈會碰到天花板

### 鉤爪(第 2 關起, 瞄準式)
22. 每代有 2 次鉤爪; 下一代出生時重新給 2 次
23. 可鉤條件: 幽靈存在、**角色著地**、**角色不是站在這隻幽靈頭上**、角色中心與幽靈中心距離 ≤ 鉤爪範圍(110)、本代還有次數。條件成立時幽靈顯示「可鉤」綠色外框與 Z 鍵帽; **幽靈此刻著地時, Z 鍵帽下方加小字「等它跳」**
   - 角色在空中、或站在幽靈頭上時, 幽靈不顯示綠框; 這時按 Z 不進入瞄準, 只響一聲 `hookDenied`(幽靈在範圍內才響)
24. 按 Z 且可鉤 → 進入「瞄準」: 時間暫停(角色、幽靈、機關、關門延遲、錄製、剩餘時間全部停住)
25. 瞄準中畫出: 角色中心到幽靈中心的虛線; 從角色中心沿同方向的箭頭, 長度 = 當下彈出速度 × 0.3 秒。蓄力值從 0 開始依真實時間增加, 1 秒到滿後停在滿。彈出速度 = 速度上限 × (0.3 + 0.7 × 蓄力值); 速度上限: 幽靈在空中用「騰空上限」850, 著地用「著地上限」400。瞄準中在玩家角色旁顯示「Z 射出 / X 取消」
26. 瞄準中再按 Z → 射出: 扣 1 次, 時間恢復; 角色速度直接設為「方向 × 彈出速度」並離開地面。射出後 0.3 秒內左右鍵無效、保留水平速度, 之後恢復一般操控(水平速度回到走速控制); 全程受重力。撞到牆、關著的門時水平速度歸零; 往上撞到天花板時垂直速度歸零。射出後 0.15 秒內畫鉤索
27. 瞄準中按 X → 取消: 不扣次數, 時間恢復
28. 瞄準中只有 Z、X、Esc、M 有作用(Esc 打開暫停選單, 關掉後回到瞄準)

**鉤爪能到多高 / 多遠**: 一次鉤爪最多讓腳底比出手時站的平面高 850² ÷ 2400 ≈ **301**(正上方、蓄滿、鉤騰空幽靈)。橫著飛: 斜 60° 蓄滿時, 頭不碰天花板的情況下落回同高平面前最多橫移約 **303**(0.3 秒內 736 × 0.3 ≈ 221, 之後走速 200 再走約 82)。出手位置只有站得住的平面; 站在幽靈頭頂時腳下那隻不可鉤; 射出後在空中不能再鉤。

## 埋點
每局結束時自動下載一個 JSON 檔(瀏覽器下載, 不需玩家操作), 檔名 `gamelog-WebGame_GhostEchoV2-<YYYYMMDD-HHMMSS>.json`, 時間為下載當下的本機時間。
- 「一局」= 某關從第 1 代開局到過關或失敗(第 3 代死亡)。過關、失敗各下載一次; 第 5 關過關後進全破畫面時再下載一次(reason `complete`)
- 每個檔包含「上次下載之後」發生的所有事件; 中途整關重來的那幾次嘗試也在裡面(重來不另外下載)
- **下載排在該批事件的最尾端**: 過關時依序記 gen_end(win)→ tutorial_hide / tutorial_skip(教學收尾)→ level_win → 下載; 失敗時 gen_end → tutorial_hide → level_lose → 下載; 全破時 game_complete → 下載
- 下載失敗不影響遊戲

檔案結構:
```json
{
  "project": "WebGame_GhostEchoV2",
  "build": "polish-10",
  "sessionStart": "2026-11-02T14:03:22+08:00",
  "downloadedAt": "2026-11-02T14:06:10+08:00",
  "reason": "win | lose | complete",
  "events": [ { "type": "...", "t": 12345, ... } ]
}
```
(build 寫在唯一一個常數裡)

所有事件共有欄位: `type`、`t`(開網頁起的毫秒, 真實時間, 瞄準與暫停照算)、`level`(1~5, 開始畫面與全破畫面的事件為 null)。事件裡的 x, y, minFeetY **都是世界座標**(世界 853⅓ × 480)。其餘欄位依事件:

| 事件 type | 何時記錄 | 其他欄位 |
|---|---|---|
| session_start | 開網頁 | levelCount(5), touch(布林, 是否觸控模式; 本輪新增, 啟動時 PVDX 尚未建立, 改在第一幀記: 見下) |
| title_start | 開始畫面按空白鍵 | waitTime(開始畫面停留毫秒) |
| level_start | 進關、或整關重來 / 失敗後重來, 第 1 代出生 | attempt(本關第幾次嘗試, 從 1 起), cause(first / restart / retry) |
| tutorial_show | 教學泡泡出現(條件式每次出現各一筆; 主線被蓋過後回來不另記) | stage, attempt, gen, count(第幾次出現, 從 1 起) |
| tutorial_key | 第 1 階段某個鍵第一次按下 | stage('move'), key(left / right / up), attempt, gen |
