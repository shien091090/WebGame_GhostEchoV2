## 新手教學
教學嵌在遊戲流程裡: 不暫停遊戲、不需要按「下一步」, 提示泡泡貼在相關物件旁, 玩家實際做到該動作才算完成。

### 共通規則
- **同時只顯示一個提示泡泡**。主線階段(第 1~8 階段)依編號順序進行: 前一階段完成(且完成特效播完、再隔 0.4 秒)後, 下一階段在它的出現條件成立時出現
- **不和開場橫幅同時出現**: 表中寫「橫幅後」的階段, 出現時機是「開場橫幅完全消失後 0.3 秒」, 即第 1 代出生後 1.8 秒; 沒有橫幅的嘗試(重來、失敗重試)是出生後 0.5 秒。橫幅還在時, 任何泡泡(含條件式)都等它消失
- **出現前就做到了 → 直接算完成**: 第 6~8 階段若在泡泡出現前玩家已做到完成條件, 直接算完成、不出泡泡、不播特效(埋點 `tutorial_done` 的 auto = true)。第 2 階段沿用原規則(第 1 代在第 1 階段完成前就死了 → 直接算完成)
- **條件式階段**(只有第 9 階段): 條件成立時立刻出現, 暫時蓋過正在顯示的主線階段(主線暫藏、它的進度保留); 條件式結束(完成或被收起)後主線回來
- 出現: 泡泡從錨點彈出 0.25 秒(`tutorialShow`)。完成: 播 0.8 秒完成特效(`tutorialDone`), 之後消失
- **已完成的階段不再出現**; 整關重來、失敗重來都不重置教學進度; 重新整理網頁才從頭(不存檔)
- 綁在某關的主線階段, 若過關時還沒完成 → 視為略過, 之後不再出現(埋點 `tutorial_skip`, 在過關當下記錄, 早於下載)。例外: 鉤爪的兩個階段(4、5)沒完成會帶到之後的關卡繼續(到第 5 關過關為止)
- 條件式階段「完成」只算做到指定動作; 若這一代結束(死亡、過關)時還沒做到, 泡泡收起(埋點 `tutorial_hide`), 條件下次再成立時再出現
- 顯示時機: 只在遊玩中(phase play)顯示。死亡演出中不顯示新泡泡, 但正在播的完成特效照播完; 瞄準暫停中只顯示第 5 階段, 其他階段暫藏(瞄準結束回來); 暫停選單打開時全部暫藏、計時一起停; 過關回放、失敗畫面、解鎖頁不顯示; 過關當下若有完成特效在播, 直接收掉
- **座標**: 下表錨點寫**世界座標**, 遊戲端 × 1.5 換成畫面座標傳給 drawTutorial; `tail`、泡泡尺寸、標示框是**畫面座標**。標示框 = 被標物件的世界框 × 1.5 後四邊各外擴 6 px(畫面座標), 上緣不高於 48(HUD 下緣)
- 泡泡跟著錨點移動(錨點是角色或幽靈時每幀跟著走)。`above`: 泡泡在錨點上方, 尾巴朝下指向錨點; 若泡泡頂緣會 < 56(畫面座標, 壓到 HUD)就改成 `below`, 錨點同時改成角色 / 幽靈的腳底中點 (x+10, y+32)。`left` / `right`(只有第 5 階段用): 泡泡在錨點左 / 右側, 垂直置中於錨點, 尾巴橫向指向錨點。左右夾在畫布內(邊距 12 px), 上下夾在 56~708 內, 夾邊後尾巴仍指向錨點
- **避開聲音開關圖示(本輪新增)**: 遊戲端每幀傳 `avoid` = 聲音開關圖示框四邊外擴 6 = 畫面 **(1222, 50, 52, 52)**(x 1222~1274、y 50~102; 觸控模式不畫圖示, 但同位置是發布時的選單鍵, 照傳)。泡泡照上面排好、夾進畫布之後, 若泡泡本體和 avoid 重疊:
  - `above` / `below`: 泡泡水平往左推到右緣 = 1216(avoid 左緣再留 6), 垂直不動; 尾巴尖端仍在 (ax, ay), 尾巴根部留在泡泡底 / 頂邊上、離泡泡右緣至少 12, 尾巴可以斜
  - `left` / `right`: 泡泡往下推到頂緣 = 108(avoid 下緣再留 6)
  - 完成特效、pop 縮放以推開後的泡泡為準
- 泡泡尺寸(畫面座標, 版位驗算用): 高 52、寬依字數最多 300, 字 16 px。`tail` = 錨點到泡泡近端邊緣的距離, 依下表
- 泡泡內容: 一行短字 + 按鍵圖示(鍵帽樣式與 drawGhost 的 Z、drawAim 同一種)。有「標示框」的階段, 另在指定物件外圍畫一個脈動的虛線框

## 概述
走到終點前必須先死, 死掉的自己變成不斷重演的幽靈, 下一個自己踩它、搭它、鉤它, 讓它守住開關、壓翹翹板, 三個人內摸到旗子。

看關卡 → 第 1 代替第 2 代鋪路(站位、跳、守開關)後死去 → 第 2 代利用第 1 代幽靈上到高處, 再替第 3 代鋪路後死去 → 第 3 代只看得到第 2 代, 利用它到終點 → 看三代合力回放 → 下一關多一樣新東西。

## 埋點
每局結束時自動下載一個 JSON 檔(瀏覽器下載, 不需玩家操作), 檔名 `gamelog-WebGame_GhostEchoV2-<YYYYMMDD-HHMMSS>.json`, 時間為下載當下的本機時間。
- 「一局」= 某關從第 1 代開局到過關或失敗(第 3 代死亡)。過關、失敗各下載一次; 第 5 關過關後進全破畫面時再下載一次(reason `complete`)
- 每個檔包含「上次下載之後」發生的所有事件; 中途整關重來的那幾次嘗試也在裡面(重來不另外下載)
- **下載排在該批事件的最尾端**: 過關時依序記 gen_end(win)→ tutorial_hide / tutorial_skip(教學收尾)→ level_win → 下載; 失敗時 gen_end → tutorial_hide → level_lose → 下載; 全破時 game_complete → 下載
- 下載失敗不影響遊戲

檔案結構:
```json
{
  "project": "WebGame_GhostEchoV2",
  "build": "polish-9",
  "sessionStart": "2026-11-02T14:03:22+08:00",
  "downloadedAt": "2026-11-02T14:06:10+08:00",
  "reason": "win | lose | complete",
  "events": [ { "type": "...", "t": 12345, ... } ]
}
```
(build 寫在唯一一個常數裡)

所有事件共有欄位: `type`、`t`(開網頁起的毫秒, 真實時間, 瞄準與暫停照算)、`level`(1~5, 開始畫面與全破畫面的事件為 null)。事件裡的 x, y, minFeetY **都是世界座標**(世界 853⅓ × 480)。其餘欄位依事件:

| 事件 type | 何時記錄 | 其他欄位 |
|---|---|---|
| session_start | 開網頁 | levelCount(5) |
| title_start | 開始畫面按空白鍵 | waitTime(開始畫面停留毫秒) |
| level_start | 進關、或整關重來 / 失敗後重來, 第 1 代出生 | attempt(本關第幾次嘗試, 從 1 起), cause(first / restart / retry) |
| tutorial_show | 教學泡泡出現(條件式每次出現各一筆; 主線被蓋過後回來不另記) | stage, attempt, gen, count(第幾次出現, 從 1 起) |
| tutorial_key | 第 1 階段某個鍵第一次按下 | stage('move'), key(left / right / up), attempt, gen |
| tutorial_done | 教學階段完成 | stage, attempt, gen, showTime(第一次出現到完成的毫秒, 不含暫停; 直接算完成的為 0), auto(布林; 第 2 階段提前死亡、第 6~8 階段在泡泡出現前就做到時為 true), x, y(此刻角色左上) |
| tutorial_hide | 條件式階段未完成就收起 | stage, attempt, gen, reason(genEnd / levelEnd) |
| tutorial_skip | 主線階段過關時未完成(過關當下記, 早於 level_win) | stage, shown(有沒有出現過) |
| gen_start | 每代出生 | attempt, gen |
| gen_end | 每代死亡或過關、或整關重來中斷 | attempt, gen, cause(pit / spike / timeout / win / restart), x, y, duration(錄製幀數), minFeetY(腳底到過的最高點), hooksUsed, timeLeft(剩餘秒數, 一位小數) |
| time_warn | 某代剩 10 秒(每代最多一次) | attempt, gen, x, y, minFeetY |
| hook | 瞄準結束(射出或取消) | attempt, gen, result(launch / cancel), ghostAir, charge, x, y |
| hook_denied | 按 Z 但不能鉤, 且幽靈在範圍內 | attempt, gen, reason(air / onGhost), x, y |
| seesaw_launch | 角色被翹翹板彈起 | attempt, gen |
| pause_open | 按 Esc 打開暫停選單 | attempt, gen, aiming(布林, 是否在瞄準中打開) |
| pause_close | 暫停選單關閉 | attempt, gen, choice(resume / restart), pauseTime(這次暫停毫秒) |
| restart | 暫停選單選「重來」(緊接在 pause_close 之後) | attempt, gen, x, y, attemptTime(本次嘗試已經過毫秒) |
| level_win | 過關 | attempt, gen, attemptTime, levelTime(本關第一次 level_start 到現在, 含失敗與重來), fails, restarts, pauseTime(本關累計暫停毫秒, 含所有嘗試) |
| level_lose | 第 3 代死亡(死亡演出結束、失敗畫面出現時) | attempt, attemptTime, fails(含這次) |
| unlock | 解鎖頁出現 | ability(hook) |
| mute | 按 M | muted |
| game_complete | 進全破畫面(第 5 關回放後按空白鍵) | totalTime(第一次 level_start 到現在) |

(相對上一版: build 改 polish-9; 刪事件 whistle、button、crusher_fall; gen_end 刪 whistles 欄位與 cause crush; unlock.ability 只剩 hook; level 範圍 1~5。時間欄位 attemptTime / levelTime / totalTime 是真實時間、含暫停, 要扣暫停用 pauseTime)

能算出的指標:
- 每關通過時間: level_win.levelTime(扣 pauseTime 即實際遊玩)、最後一次嘗試的 attemptTime
- 失敗次數: level_lose 與 restart 的筆數, level_win.fails / restarts 直接給答案
- 卡關位置: gen_end 的死因、x, y、minFeetY, restart 的 x, y。第 2 關: 第 2、3 代 minFeetY > 241 = 沒上平台一; 第 3、4 關: 第 3 代 minFeetY > 146 = 沒上平台二, 第 3 代 gen_end 在平台二(y ≤ 118)且 cause timeout = 等不到門開; 第 5 關: 第 2、3 代 minFeetY > 146 = 沒上中層, 第 3 代 gen_end.x 在 400~630 且 cause pit = 鉤缺口沒飛過去
- 自殺點遠近(H52): 每關第 1 代 gen_end.duration(幀)與 cause
- 新手教學(H49): 各階段 tutorial_show.t、tutorial_done.t 與 showTime; 第 1 階段三鍵各在何時按到; 哪些被略過、第 9 階段出現幾次; 開始畫面停留多久
- 暫停選單: pause_open 次數、choice 比例; 第 9 階段出現後有沒有接著 pause_close(restart)
- 第 5 關(最後一關): 第 3 代 hook 事件的 charge 與 levelTime, 和第 2~4 關比較是否最難

## 範圍邊界
- 五關, 依序進行, 不能選關; 不存檔、無計分、無計時排行
- 無怪物; 無「這一代重來」、無重錄上一代, 只有整關重來(暫停選單)
- 無起跑哨(本輪移除); 幽靈只能照紀錄自然循環
- 鉤爪只能鉤幽靈; 只能站著出手
- 每關最多一個升降台、一組門、一座翹翹板
- 無慢動作(瞄準暫停除外); 不做手把; 觸控層發布時才加(手機選單鍵在右上角, 由發布的觸控層設定)
- 整關一畫面, 不做捲動鏡頭(玩家要看到整關與上一代路線才能規劃)
- 只畫設計區 1280 × 720; 觸控裝置變寬時兩側由觸控層塗黑
- 沒有說明頁; 新手教學不能手動關閉或跳過, 也沒有「重看教學」
