# 幽影接力(打磨版第 3 輪: 七關, 能力解鎖制)

## 本輪改動
相對底版 polish-2/game(六關版), 美術、RD、音效要動的地方:

1. **每代剩餘時間顯示**(H42): 60 秒上限保留; HUD 顯示這一代還剩幾秒, 最後 10 秒變色、最後 5 秒每秒一聲 `timeTick`(規則 6a)。RD: drawHud 新增 `timeLeft`、`timeMax`; 美術: HUD 計時器; 音效: 新增 `timeTick`
2. **翹翹板彈射速度 1550 → 1900 px/s**(約升 500 → 752 px; 第 5、7 關), 讓「非翹翹板不可」的落差(680 px)高過鉤爪極限(602 px)(H43)。驗算見「關卡」各關
3. **鉤爪只能站著出手**(新規則 23): 角色著地(地面、平台、升降台、翹翹板、幽靈頭頂)才可鉤; 站在幽靈頭上時, 腳下那隻幽靈不可鉤。理由: 不加這條, 角色跳到空中、貼在跳起的幽靈正下方出鉤, 實際可升到地面以上約 770 px, 比翹翹板還高, 翹翹板又會被繞過。這條同時解決新手「一直往腳下的幽靈出鉤」(H44)
4. **幽靈著地時鉤爪提示多一句「等它跳」**: 綠框旁的 Z 鍵帽下方加小字(drawGhost 新增 `hookAir`)
5. **修出生點 bug**(H44): 角色只會在「從上方落到幽靈頭頂」時站上去; 身體和幽靈重疊時(含出生當下與站在出生點的幽靈重疊), 幽靈不會把角色頂上去(規則 11)
6. **畫面上緣 y 100(HUD 下緣)是天花板**(規則 4): 角色頭頂撞到即停住往上的速度。防止新高度下從中層一鉤飛過壓板頂端
7. **關卡由六關改七關**: 第 5 關重做(兩層, 地面 → 中層 680 px 只能靠翹翹板, 拿掉門); **新增第 6 關「叫他回來」**(單層的練哨關: 起跑哨 + 按鈕 + 壓板第一次出現, 只要再吹一次就過); 原第 6 關改為**第 7 關「撐住壓板」**, 依新的彈射高度重排高度(中層 780 → 520、頂層 360 → 260, 壓板變短)。難度分析指出第 5 → 6 關太陡、第 3 → 5 關太平
8. **壓板節奏燈**(新, 第 6、7 關): 壓板上一盞燈告訴玩家「現在吹哨接不接得上」: 綠(現在吹, 附 C 鍵帽)/ 黃(他正走向按鈕, 別吹)/ 紅(來不及了)(規則 43a)。drawCrusher 新增 `cue`
9. 壓板的頂端與落下位置改由各關給(drawCrusher 已有 `top`、`bottom`); 第 6 關壓板從 y 100 一路垂到地面
10. 關卡卡片: 第 7 關 newThing 新值 `'final'`(畫翹翹板與壓板並排, 表示綜合關)
11. 埋點: build 改 `polish-3`; 新增 `hook_denied`、`time_warn`; whistle 加 `cue`; gen_end 加 `timeLeft`; levelCount 7
12. 音效: 新增 `timeTick`、`hookDenied`; 背景音樂不變

驗證假設: H41(換做法重驗)、H45、H46(並沿用 H03 H05 H07 H11 H12 H13 H14 H18 H23 H27 H28 H30 H33 H35 H38 H42 H43 H44)

## 概述
走到終點前必須先死, 死掉的自己變成不斷重演的幽靈, 下一個自己踩它、搭它、鉤它, 讓它守住開關、反覆踩按鈕, 三個人內摸到旗子。
七關, 每關多一樣新東西; 能力解鎖: 過第 1 關得鉤爪、過第 5 關得起跑哨。

## 核心循環
看關卡 → 第 1 代替第 2 代鋪路(站位、跳、守開關)後死去 → 第 2 代利用第 1 代幽靈上到中層, 再替第 3 代鋪路後死去 → 第 3 代只看得到第 2 代, 利用它到終點 → 看三代合力回放 → 下一關多一樣新東西。

## 規則
### 基本
1. 每關單一畫面, 不捲動。座標以畫布左上為原點, y 向下
2. 角色左右走、跳躍; 受重力, 落地才能起跳(地面、平台、升降台、翹翹板、幽靈頭頂都算落地)
3. 地面與「實心平台」為實心(從下方撞到會停住、頂面可站); 一般空中平台、升降台、翹翹板為單向平台: 從下方可穿過, 從上方落下時會站上去。牆、關著的門、尖刺壓板的側面為實心, 擋住角色
4. 角色掉出畫面下緣即死亡; 碰到尖刺即死亡; 角色左右不能走出畫布。**y 100(HUD 下緣)是天花板: 角色頭頂到達 y 100 時停在那裡, 往上的速度歸零**(新; 幽靈照紀錄重播, 不受影響)
5. 共三代角色, 第 1 代開局出生在出生點(每關都是 x 60, y 1144)
6. 每代從出生到死亡的每一幀都被記錄(60 幀/秒): 位置、朝向、動作狀態、是否著地、鉤索兩端(只在彈出後的鉤索顯示時間內才有)、「這一幀上一代幽靈播到第幾幀」(第 1 代沒有, 記空)、第 6、7 關另記「這一幀壓板底部 y」(給過關回放用)。瞄準暫停期間時間不前進、不記錄。錄製達 60 秒時該代自動死亡(cause timeout)
   - 6a. **剩餘時間顯示**(新): HUD 顯示「這一代還剩幾秒」(60 − 已錄製秒數, 無條件進位成整數秒顯示, 並配一條隨時間縮短的量條)。剩 10 秒起數字與量條變成警告色; 剩 5、4、3、2、1 秒時各響一聲 `timeTick`。瞄準暫停時一起停住。死亡演出、過關回放、失敗畫面時不顯示
7. 某代死亡後播放 0.6 秒死亡演出, 接著下一代在出生點出生; 升降台、門、翹翹板、尖刺壓板回到初始狀態, 按鈕的「本輪已觸發」全部清除, 之後再依當下狀態運作
8. 新一代出生的同一幀, 上一代的紀錄從第 0 幀開始以「幽靈」重播; 播完最後一幀後立刻從第 0 幀重新開始, 無限循環
9. 場上只存在「上一代」的幽靈: 操控第 2 代時只有第 1 代幽靈; 操控第 3 代時只有第 2 代幽靈, 第 1 代幽靈完全消失(不顯示、不可踩、不可鉤、不壓開關、不踩按鈕、不觸發翹翹板)
10. 幽靈不受尖刺、坑洞、門、牆、升降台、翹翹板、實心平台、尖刺壓板、天花板影響, 純粹照紀錄重播; 紀錄中帶鉤索的幀, 幽靈連同它的鉤索一起顯示
11. 幽靈只有頭頂可以站。**站上去的條件(改, 修出生點 bug)**: 這一幀角色往下或不動(垂直速度 ≥ 0)、水平與幽靈重疊, 且「上一幀角色腳底 ≤ 上一幀幽靈頭頂」、「這一幀角色腳底 ≥ 這一幀幽靈頭頂」——也就是角色是從幽靈頭頂上方落下來的。幽靈這一幀是瞬移(循環接回第 0 幀、吹哨跳回第 0 幀)時, 「上一幀幽靈頭頂」改用這一幀的頭頂。角色身體和幽靈重疊時(例: 新一代出生時, 上一代幽靈的第 0 幀就在出生點、兩者完全重疊), 幽靈怎麼移動都不會把角色頂上去; 出生當下角色一律站在地面上。幽靈的其他部位不擋角色
12. 站在幽靈頭上時, 角色跟著幽靈移動(水平位移相加, 腳底每幀貼齊幽靈頭頂, 幽靈上升或下降都跟著); 可以從幽靈頭上起跳; 水平走出幽靈頭頂範圍即離開
13. 幽靈循環從最後一幀跳回第 0 幀時, 站在它頭上的角色不跟著瞬移, 改為進入空中狀態

### 前一代路線(5 秒)
14. 畫面畫出當前幽靈「從目前這一幀起、接下來 300 幀(5 秒)」的紀錄位置, 單一顏色, 小圓點畫法沿用底版。紀錄剩不到 300 幀時接回第 0 幀繼續畫, 但總長最多一整圈; 接回處斷開成兩段, 不連線。不畫已經走過的部分、不分色、不加預影

### 能力解鎖
15. 能力依關卡開放: 第 1 關沒有鉤爪也沒有起跑哨; 第 2 關起有鉤爪; 第 6 關起有起跑哨。未開放時按對應的鍵不發生任何事, HUD 也不顯示該能力
16. 第一次通過第 1 關、第 5 關後, 過關回放結束按空白鍵會先出現「解鎖頁」(第 1 關後: 鉤爪; 第 5 關後: 起跑哨), 再按空白鍵進下一關

### 起跑哨(第 6、7 關)
17. 按 C 吹哨: 場上的幽靈立刻跳到紀錄第 0 幀(出生點)從頭重播, 算「新的一輪」(對按鈕而言, 見規則 38)。路線跟著從第 0 幀重畫
18. 吹哨的那一幀, 站在幽靈頭上的角色不跟著瞬移, 改為進入空中狀態(同規則 13); 幽靈原本壓住的開關若因此放開, 照一般規則處理
19. 吹哨不限次數、沒有冷卻; 場上沒有幽靈時(第 1 代)按 C 不發生任何事; 瞄準中按 C 無效
20. 吹哨時在幽靈的新位置(出生點)播放一圈擴散的「哨音波紋」0.4 秒
21. 吹哨只改變幽靈「播到哪一幀」, 不改動任何紀錄; 這一代自己的錄製照常進行(吹哨不算重來)

### 鉤爪(第 2 關起, 瞄準式)
22. 每代有 2 次鉤爪; 下一代出生時重新給 2 次
23. **可鉤條件(改)**: 幽靈存在、**角色著地**(站在地面、平台、升降台、翹翹板或幽靈頭頂)、**角色不是站在這隻幽靈頭上**、角色中心與幽靈中心距離 ≤ 鉤爪範圍(220 px)、本代還有次數。條件成立時幽靈顯示「可鉤」綠色外框, 框旁顯示一個 Z 按鍵圖示; **幽靈此刻著地時, Z 圖示下方加小字「等它跳」**(著地上限只有 800 px/s, 幾乎飛不高)
   - 角色在空中、或站在幽靈頭上時, 幽靈不顯示綠框; 這時按 Z 不進入瞄準, 只響一聲輕的 `hookDenied`(幽靈在範圍內才響, 讓玩家知道「現在不行」而不是按鍵壞了)
24. 按 Z 且可鉤 → 進入「瞄準」: 時間暫停(角色、幽靈、升降台、門、翹翹板演出、壓板與它的倒數、關門延遲、錄製、剩餘時間全部停住)。按 Z 但不可鉤: 不進入瞄準(見 23)
25. 瞄準中畫出: 從角色中心到幽靈中心的虛線(彈出方向); 從角色中心沿同方向的箭頭, 長度 = 當下彈出速度 × 0.3 秒。蓄力值從 0 開始依真實時間增加, 1 秒到滿後停在滿。彈出速度 = 速度上限 × (0.3 + 0.7 × 蓄力值); 速度上限看幽靈當下狀態: 在空中(紀錄中未著地)用「騰空上限」, 著地用「著地上限」。瞄準中在玩家角色旁顯示「Z 射出 / X 取消」
26. 瞄準中再按 Z → 射出: 扣 1 次, 時間恢復; 角色速度直接設為「方向 × 彈出速度」並離開地面或幽靈頭頂。射出後的「彈射時間」內左右鍵無效、保留水平速度, 之後恢復一般操控; 全程受重力。撞到牆、關著的門、壓板側面時水平速度歸零; 往上撞到實心平台底面或天花板時垂直速度歸零。射出後在「鉤索顯示時間」內畫鉤索: 角色中心 → 被鉤幽靈當下中心
27. 瞄準中按 X → 取消: 不扣次數, 時間恢復, 角色維持暫停前的狀態
28. 瞄準中只有 Z、X、R、M 有作用; 其他按鍵無效

**鉤爪能到多高(給 RD / 關卡驗算)**: 因為只能站著出手, 一次鉤爪最多讓腳底比出手時站的平面高 1700² ÷ (2 × 2400) ≈ **602 px**(正上方、蓄滿、鉤騰空幽靈)。出手位置只有「站得住的平面」(地面、平台、升降台、翹翹板); 幽靈頭頂雖然能站, 但站在上面時唯一的幽靈就是腳下那隻、不可鉤, 所以不構成更高的出手點。射出後在空中不能再鉤, 也就沒有「鉤完再鉤」的接力。

### 開關、門、升降台(第 3、4 關)
29. 開關被壓住的條件: 角色或場上的幽靈處於著地狀態, 腳底與開關所在平面同高, 且水平與開關有重疊
30. 門在門開關被壓住期間開啟; 開關放開後經過該關的「關門延遲」才關上。門關著時是實心牆, 跳不過。門要關上的那一刻若角色與門重疊, 門延後到角色離開後才關
31. 升降台開關被壓住期間, 升降台以「升降速度」往上移, 到最高點停住; 放開後以同速往下移, 回到最低點停住。站在升降台上的角色一律跟著上下移動: 判定為「角色著地、腳底與升降台頂面同高(誤差 1 px 內)、水平與升降台有重疊」, 每幀在升降台移動之前判定; 升降台在最低點、頂面與地面齊平時, 站在那一段地面上的角色同樣算站在升降台上。升降台最低點時頂面與地面齊平, 下方地面一直存在; 升降台不會夾死角色
32. 每個開關、按鈕與它控制的物件用同一種顏色標示

### 翹翹板(第 5、7 關)
33. 翹翹板嵌在平面上, 有兩端: 左邊「落點端」、右邊「發射端」(各 80 px), 中間 40 px 為板身; 兩端頂面與所在平面齊平, 可以正常站、走過
34. 觸發: 角色或場上的幽靈「從空中落到落點端上」——上一幀未著地、這一幀著地, 腳底與翹翹板平面同高且水平與落點端有重疊。幽靈以紀錄判斷(比較紀錄中相鄰兩幀; 循環從最後一幀接回第 0 幀、吹哨跳回第 0 幀都不算)
35. 觸發的那一幀, 所有「著地站在發射端上」的角色(腳底與平面同高、水平與發射端重疊)垂直速度設為向上「彈射速度」(**1900 px/s, 約升 752 px**)、水平速度歸零, 進入空中狀態, 之後可正常左右移動。幽靈站在發射端上不受影響
36. 觸發時翹翹板播放「落點端壓下、發射端翹起」的擺動演出 0.3 秒後回平; 沒人站在發射端時也照樣擺動。演出中仍可再次觸發

### 按鈕與尖刺壓板(第 6、7 關)
37. 按鈕嵌在地面上; 「踩到按鈕」的條件同開關(規則 29): 角色或場上的幽靈著地、腳底與地面同高、水平與按鈕重疊
38. 每一輪只觸發一次: 玩家角色每一代(出生到死亡)只能觸發一次; 幽靈每一輪重播只能觸發一次——「一輪」從幽靈播到第 0 幀開始, 自然循環接回第 0 幀、或吹哨跳回第 0 幀, 都開始新的一輪。同一輪裡離開再踩上去、或一直站著, 都不再觸發
39. 觸發時, 壓板的「升起倒數」設為「升起時間」(1.2 秒); 已經在倒數中再被觸發, 倒數重新設回 1.2 秒(不疊加)
40. 尖刺壓板是一根從「壓板頂端」(各關給; 都是 y 100, 即天花板)垂下的實心柱, 底面整排尖刺。倒數 > 0 時壓板以「壓板速度」往上收 90 px 到「升起位置」並停住, 倒數照遊戲時間遞減(瞄準暫停時停住); 倒數歸零時以同速往下落回「落下位置」(底面與所在平面頂面齊平, 把路完全堵死)
41. 角色碰到壓板底面的尖刺即死亡(cause crush): 包括壓板往下落時壓到角色、角色在壓板下方跳起撞到尖刺。壓板的左右側面像牆一樣擋住角色
42. 壓板要讓玩家看得出還剩多久落下: 升起時壓板上顯示倒數(隨剩餘時間縮短的量條或燈號), 最後 0.3 秒閃爍警告
43. 按鈕與壓板同一種顏色(與升降台、門開關的顏色都不同)
43a. **節奏燈(新)**: 壓板正面一盞燈, 告訴玩家「此刻按 C 吹哨, 幽靈能不能在壓板落下前再踩到按鈕」。先由遊戲算出 **tb** = 目前幽靈的紀錄中, 第一次踩到按鈕的那一幀(從第 0 幀起算; 換算秒數 = tb ÷ 60)。燈有四種狀態, 每幀依序判斷:
   - `none` 不亮: 場上沒有幽靈, 或幽靈的紀錄從沒踩過按鈕(吹了也沒用)
   - `wait` 黃燈: 幽靈這一輪還沒走到按鈕(目前播放幀 < tb)——他正在路上, 現在吹會把他叫回起點、反而更晚踩到
   - `late` 紅燈: 幽靈這一輪已經踩過(播放幀 ≥ tb), 壓板正在倒數, 但剩餘倒數 ≤ tb 秒——現在吹, 他踩到之前壓板就會落下
   - `ok` 綠燈 + 燈旁 C 鍵帽: 其餘情況(幽靈這一輪已經踩過, 且壓板沒在倒數或剩餘倒數 > tb 秒)——現在吹, 接得上
   - 只有吹哨已解鎖的關卡顯示; 瞄準中照常顯示(凍結); 過關回放不顯示

### 結束
44. 「整關重來」(R): 回到本關第 1 代開局, 清空本關所有紀錄。沒有其他任何重來方式
45. 角色碰到終點旗即過關(同一幀若同時碰到旗子與尖刺 / 壓板, 算過關)
46. 過關後進入回放, 重現每一代當時「看到的幽靈在哪一幀」(含吹哨造成的跳轉): 以過關那一代的紀錄為主軸, 從第 0 幀播到過關那一幀後循環; 主軸第 f 幀時, 上一代以「主軸第 f 幀記下的上一代播放幀」顯示, 再上一代以「上一代那一幀記下的播放幀」顯示, 一路往前推。各代都顯示(含鉤索); 開關、門、升降台照回放中的壓住狀態運作, 翹翹板在回放中有人落到落點端時照樣擺動(只是演出); 第 6、7 關的壓板照主軸紀錄的「壓板底部 y」顯示。回放時不畫路線、不畫哨音波紋、不畫按鍵提示、不畫節奏燈、不顯示剩餘時間; 回放中只有空白鍵與 M 有作用。若過關的是第 2 代, 只回放第 1、2 代

- 第 2 代: 站到壓板左邊(x ≤ 160)按 C → 第 1 代幽靈回到出生點、下一幀就踩到按鈕 → 壓板升起 → 往右跑; 跑到一半節奏燈還是綠的, 再按一次 C → 倒數重設 → 摸到旗子。第 2 代自己出生時也會踩到按鈕(玩家每代一次), 可以直接利用這一次升起再吹一次
- 第 3 代: 若第 2 代失敗, 第 3 代看到的是第 2 代(它也踩過按鈕), 做法相同

驗算:
- 單次升起過不去: 壓板升到底面高於頭頂(1144)要 56 ÷ 600 ≈ 0.093 秒; 倒數 1.2 秒歸零後落 0.093 秒壓到頭, 可在壓板下的時間 = 1.2 秒 ≈ 跑 312 px。角色最早在壓板升到頭頂以上時, 位於壓板左側 x 160, 之後最多跑到 160 + 312 = 472; 碰到旗子要 x > 512, 差 40 px(約 0.15 秒) → 壓死。按鈕在哪一點踩都一樣: 角色進壓板下之前一定在 x ≤ 160
- 再吹一次就過: 第 1 代幽靈若出生就往右走, tb ≈ 0.02 秒, 吹哨後幾乎立刻踩到; 第一次觸發後到倒數歸零前(約 1.2 秒內)任何時刻再吹, 倒數就重設, 可在壓板下的時間延長到 2 秒以上, 遠大於需要的 1.35 秒。節奏燈在這段幾乎都是綠燈
- 第 1 代若出生後先發呆再走, tb 會變長, 節奏燈的黃燈時間跟著變長——第 7 關要用到的「看燈吹」在這裡先看到
- 天花板讓壓板無法從上方越過; 鉤爪飛不過(頭頂到 y 100 就停)
- 自然循環的捷徑: 第 1 代若一踩按鈕就在壓板下跳起撞尖刺自殺(約 0.55 秒), 它的幽靈一輪只有約 0.55 秒、每輪都踩一次按鈕, 壓板會一直撐著, 第 2 代不吹哨也能過。這要玩家自己想通「一輪越短、踩得越勤」, 和吹哨是同一個道理, 不擋

### 第 7 關 撐住壓板(原第 6 關, 依新彈射高度重排)
三層: 地面(第一層)、中層(第二層)、頂層(第三層)。按鈕在出生點前方, 右邊是翹翹板; 頂層有一根帶尖刺的壓板堵住通往旗子的路。相對 polish-2: 中層 780 → 520(地面上中層改為只有翹翹板上得去)、頂層 360 → 260、壓板高度跟著變短(底面 260 / 170), 其餘(按鈕、翹翹板、壓板寬 360、升起時間)不變。

設計意圖:
- 第 1 代: 往右走(順路踩過按鈕, 這時沒用), 在翹翹板落點端反覆跳, 之後往右走進坑
- 第 2 代(三件事, 使用者原設計): (1) 出生後直接往右走, 約 0.23 秒踩到按鈕——這是之後每次被吹哨叫回時的動作, 走得越乾脆, 第 3 代的黃燈越短; (2) 站上翹翹板發射端, 等第 1 代落下, 被彈到腳底約 448 落在中層; (3) 走到中層 x 540~620 跳一次給第 3 代, 之後從中層右端走進坑
- 第 3 代: (a) 跳上第 2 代幽靈的頭被載著走, 隨它被翹翹板彈上中層(第 2 代若先在落點端跳一下, 也可站發射端被彈); (b) 第 2 代在中層跳起時鉤它, 或站在它頭上隨它跳再起跳, 上到頂層右段; (c) 站在壓板右側看節奏燈吹哨 → 壓板升起 → 往左鑽; 途中燈再變綠就再吹, 讓壓板一直撐著, 跑到旗子
- 和第 6 關的差別: 要先爬兩層才摸得到壓板; 壓板寬 360(第 6 關 340)且第 2 代走到按鈕要約 0.23 秒(第 6 關幾乎 0), 吹哨後要等黃燈過去, 吹太密會把第 2 代一直叫回起點

驗算:
- 中層只有翹翹板上得去: 地面出手點腳底 1200, 鉤爪最高 598 > 520; 踩第 1 代跳躍再跳 808 > 520; 翹翹板 448 < 520 ✓。被彈的人頭頂最高 392, 碰不到頂層底(284)
- 第 3 代在地面鉤正在被彈起的第 2 代: 站立出手最高 598 > 520, 上不去; 只能搭便車或自己被彈(使用者確認搭便車不算捷徑)
- 中層 → 頂層右段: 鉤第 2 代中層跳躍(中心相距 168 ≤ 220, 需升 260 + 少許, 蓄力約一半), 或騎它跳躍再跳(腳底最高約 128 < 260)
- 繞過壓板的路都堵死: 壓板從天花板 y 100 頂到底, 跳不過也鉤不過(頭頂到 y 100 就停); 頂層左段為實心, 從中層或地面往上會撞到底面, 不能從下方鑽到旗子那一側; 頂層右段以外往上穿過 y 260 的位置都在實心段或壓板正下方
- 單次升起跑不過去: 角色從 x 500 跑到 x 100(右緣 140 離開壓板)共 400 px, 需 1.54 秒; 單次可通行時間 1.2 秒(跑 312 px), 差 88 px → 至少要再觸發一次
- 吹哨接得上: 第 2 代 tb ≈ 0.23 秒時, 第一次觸發後, 在幽靈踩到按鈕之後到倒數剩 0.23 秒之前(約 0~0.97 秒)再吹, 倒數就會在壓板落下前重設——這正是節奏燈的綠燈區間。第 2 代若走得慢(polish-2 實測 0.58~1.2 秒), 綠燈區間縮短; tb ≥ 1.2 秒時綠燈只在壓板沒倒數時亮, 吹了也接不上, 玩家看得到「整段都是紅燈」, 就知道要回頭重錄第 2 代(整關重來)
- 第 2 代自然循環(一輪約 5 秒以上)也會順便踩一次按鈕, 但單靠自然循環接不上; 一定要吹哨(H41)
- 第 2 代上不了頂層: 第 1 代永遠在地上, 中層上的第 2 代到第 1 代跳躍最高中心相距 512 > 220
- 壓板只在頂層, 第 1、2 代碰不到; 第 3 代在壓板下被壓到 → 本關失敗

## 埋點
每局結束時自動下載一個 JSON 檔(瀏覽器下載, 不需玩家操作), 檔名 `gamelog-WebGame_GhostEchoV2-<YYYYMMDD-HHMMSS>.json`, 時間為下載當下的本機時間。
- 「一局」= 某關從第 1 代開局到過關或失敗(第 3 代死亡)。過關、失敗各下載一次
- 每個檔包含「上次下載之後」發生的所有事件; 中途按 R 整關重來的那幾次嘗試也在裡面(R 不另外下載)
- 下載失敗不影響遊戲

檔案結構:
```json
{
  "project": "WebGame_GhostEchoV2",
  "build": "polish-3",
  "sessionStart": "2026-10-09T14:03:22+08:00",
  "downloadedAt": "2026-10-09T14:06:10+08:00",
  "reason": "win | lose",
  "events": [ { "type": "...", "t": 12345, ... } ]
}
```
所有事件共有欄位: `type`、`t`(開網頁起的毫秒, 瞄準暫停照算真實時間)、`level`(1~7, 說明頁與全破畫面的事件為 null)。其餘欄位依事件:

| 事件 type | 何時 | 其他欄位 |
|---|---|---|
| session_start | 開網頁 | levelCount |
| guide_page | 說明頁翻頁 | from, to(頁碼 0~4), dir(next / prev) |
| guide_done | 說明頁翻完 | pagesTime(停留毫秒), backs(按 ← 回頭的次數) |
| level_start | 關卡卡片按空白鍵、或 R / 失敗後重來, 第 1 代出生 | attempt(本關第幾次嘗試, 從 1 起), cause(first / restart / retry) |
| gen_start | 每代出生 | attempt, gen |
| gen_end | 每代死亡或過關 | attempt, gen, cause(pit / spike / crush / timeout / win / restart), x, y(角色左上), duration(這代錄製幀數), minFeetY(這代腳底到過的最高點, y 最小值), hooksUsed, whistles, **timeLeft(剩餘秒數, 一位小數)** |
| time_warn | 某代剩 10 秒(每代最多一次) | attempt, gen, x, y, minFeetY(到目前為止) |
| hook | 瞄準結束 | attempt, gen, result(launch / cancel), ghostAir(布林), charge(0~1), x, y |
| hook_denied | 新: 按 Z 但不能鉤, 且幽靈在範圍內(鉤爪已解鎖、還有次數) | attempt, gen, reason(air: 角色在空中 / onGhost: 站在這隻幽靈頭上), x, y |
| whistle | 吹哨 | attempt, gen, x, y, ghostFrame(吹哨前幽靈播到第幾幀), crusherLeft(吹哨當下壓板升起倒數剩餘毫秒, 沒有壓板的關為 null), **cue(吹哨當下節奏燈: ok / wait / late / none)**, tb(這隻幽靈走到按鈕的幀數, 沒有則 null) |
| button | 按鈕被觸發 | attempt, gen(目前操控的代), by(player / ghost) |
| crusher_fall | 壓板倒數歸零、開始落下 | attempt, gen, upTime(這次連續升起了多少毫秒), playerX(此刻角色左上 x) |
| seesaw_launch | 角色被翹翹板彈起 | attempt, gen |
| restart | 按 R | attempt, gen, x, y, attemptTime(本次嘗試已經過毫秒) |
| level_win | 過關 | attempt, gen(過關的代), attemptTime, levelTime(本關第一次 level_start 到現在的毫秒, 含之前所有失敗與重來), fails(本關失敗次數), restarts(本關 R 次數) |
| level_lose | 第 3 代死亡 | attempt, attemptTime, fails(含這次) |
| unlock | 解鎖頁出現 | ability(hook / whistle) |
| mute | 按 M | muted(布林) |
| game_complete | 第 7 關過關後進全破畫面 | totalTime |

(相對底版: 新增 time_warn、hook_denied; gen_end 加 timeLeft; whistle 加 cue、tb; seesaw_launch 拿掉 which(每關最多一座翹翹板))

能算出的指標:
- 每關通過時間: level_win.levelTime(含失敗), 以及最後一次嘗試的 attemptTime
- 失敗次數: level_lose 與 restart 的筆數(依 level 分組), level_win.fails / restarts 直接給答案
- 卡關位置: 每筆 gen_end 的死因與 x, y、minFeetY(到過多高), restart 的 x, y; 依關卡與代數分組可看出卡在哪一層。第 5 關: 第 2、3 代 minFeetY > 520 = 沒上中層; 第 7 關: 第 3 代 minFeetY > 520 卡在地面、> 260 卡在中層; cause crush 的 x 表示在壓板下跑到哪裡被壓
- 剩餘時間(H42): timeout 的筆數是否比 polish-2(4 次)少; time_warn 後還能過關或主動 R 的比例
- 翹翹板(H43): 第 5、7 關每次嘗試的 seesaw_launch 筆數(應 ≥ 1, 否則表示又被繞過)
- 鉤爪站立規則(H46): hook_denied 筆數與 reason; 太多 air 表示玩家習慣空中出鉤而受挫
- 節奏燈(H45 / H41): 第 6、7 關 whistle 的 cue 分布(ok 比例越高表示看得懂燈); wait 太多 = 還在亂吹; crusher_fall 的 upTime(連續撐了多久)與 playerX
- 能力使用: hook 的取消比例與蓄力分布、whistle 次數
- 說明頁: guide_page 的 prev 筆數

- 過關: 任一代碰到終點旗 → 過關字樣 + 三代回放, 按空白鍵進下一關(或解鎖頁 / 全破畫面)
- 失敗: 第 3 代死亡 → 失敗畫面, 按空白鍵重來本關
- 全破: 第 7 關過關後顯示全破畫面

## 範圍邊界
- 七關, 依序進行, 不能選關; 不存檔、無計分、無計時排行
- 無怪物; 無「這一代重來」、無重錄上一代, 只有整關重來; 吹哨只改幽靈播放位置
- 吹哨只能讓幽靈回到第 0 幀, 不能暫停、倒轉或跳到其他幀
- 鉤爪只能鉤幽靈, 不能鉤平台、牆、升降台或壓板; 只能站著出手
- 每關最多一個升降台、一組門、一座翹翹板、一組按鈕壓板; 翹翹板只在第 5、7 關、按鈕壓板只在第 6、7 關; 沒有鑰匙與鎖
- 無慢動作(瞄準暫停除外); 不做手把與觸控
